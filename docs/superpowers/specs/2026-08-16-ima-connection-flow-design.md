# Tencent IMA 只读连接流程设计

## 背景与目标

DeepTutor v1.5.12 已具备 Tencent IMA 的后端检索管线、连接探测和按知识库保存连接信息的能力，但 Web 端没有接入这些专用接口。当前界面会把 IMA 显示为“就绪”，环境检查却因预检表缺少 `ima` 而返回 HTTP 500；创建知识库时又错误显示本地文件上传控件。

本次改动的目标是让用户在 DeepTutor 中完成 IMA 的只读连接，并让 Chat 等 RAG 消费方通过 IMA `search_knowledge` 返回的命中文档片段进行检索式问答。

## 范围

包含：

- 使用 Client ID 和 API Key 验证 IMA 访问权限。
- 自动列出当前凭据可访问的 IMA 知识库。
- 选择一个知识库并连接为 DeepTutor 知识库。
- 提供折叠的手填 Knowledge Base ID 高级入口。
- 修复 IMA 引擎预检的 HTTP 500。
- 保持服务端二次探测，避免前端验证结果被直接信任。
- 覆盖前端、后端和真实 IMA 只读检索验证。

不包含：

- 向 IMA 上传、导入、修改或删除文档与笔记。
- 下载或通读完整原始文件。
- 修改现有凭据存储机制。
- 抽象通用外部知识库连接器框架。

## 用户流程

1. 用户进入“新建知识库”，切换到“关联已有”。
2. 用户选择 Tencent IMA。
3. 页面展示 Client ID、API Key 和“验证并读取知识库”按钮；API Key 使用密码输入框。
4. 验证成功后，页面展示知识库名称与描述列表，不向普通流程暴露内部 ID。
5. 用户选择一个知识库，填写 DeepTutor 内显示的知识库名称并点击“连接”。
6. DeepTutor 服务端再次调用 IMA 验证该知识库，成功后才保存连接。
7. 后续 RAG 查询只调用 IMA 的只读检索接口，并把命中片段交给现有回答链路。

高级入口允许用户手填 Knowledge Base ID。手填后仍必须先探测成功，才能连接。

## 后端设计

### IMA 客户端

在现有 `ImaClient` 中增加按名称搜索知识库的只读方法，调用官方 `openapi/wiki/v1/search_knowledge_base`。首次查询使用空字符串并通过游标获取有限数量的知识库，返回经归一化的 ID、名称和描述。

### API 路由

新增不落盘的只读路由，用请求体接收 Client ID 和 API Key，返回当前账号可访问的知识库摘要。路由不得记录、返回或缓存凭据。

现有 `probe-ima` 继续负责验证手填 Knowledge Base ID；现有 `connect-ima` 继续执行服务端二次探测并注册连接。

### 预检

为 `ima` 注册专用预检。因为凭据按知识库配置，预检只说明“连接知识库时提供凭据”，并返回成功的说明性结果，不尝试读取全局配置。

## 前端设计

- 在知识库 API 客户端中增加 IMA 列表、探测和连接函数及其类型。
- “新建”模式不再把 IMA 当作上传型引擎。
- “关联已有”模式显式提供 IMA 入口，并渲染专用表单，而不是本地文件夹表单。
- Client ID 或 API Key 变化时清空旧的知识库列表和探测结果。
- 只有选中的知识库或手填 ID 已验证成功时，连接按钮才可用。
- 连接中、验证中、空列表、认证失败、权限不足和网络错误均使用现有错误展示样式。
- 引擎详情页的环境要求展示 IMA 的按知识库连接说明，不再显示裸 `'ima'` 错误。

## 数据与安全边界

- 凭据只通过 HTTPS 请求发送到本机 DeepTutor 后端，再由后端作为 IMA 官方请求头发送至 `ima.qq.com`。
- 日志、测试输出、错误消息和前端响应均不得包含凭据。
- 自动化测试使用虚构凭据和 HTTP mock；用户授权的真实凭据只用于本地临时 smoke test，不写入仓库、快照或测试夹具。
- 本次不改变现有连接成功后的本地配置保存行为。

## 错误处理

- 缺少凭据：前端禁用验证按钮，后端返回可读的 400 错误。
- 凭据错误或过期：展示 IMA 返回的安全错误信息，不回显请求头。
- 无可访问知识库：展示空状态，并提供手填 ID 高级入口。
- 手填 ID 不存在或无权限：探测失败，禁止连接。
- 列表验证成功但连接时状态已变化：以服务端二次探测结果为准。
- IMA 限流或网络故障：保留用户输入，允许重试。

## 测试与验收

自动化测试：

- `ImaClient` 对知识库列表的请求路径、请求体、分页、归一化和错误映射。
- 新列表路由的成功、缺少凭据、认证失败和不泄露凭据。
- IMA 预检返回说明性成功结果。
- Web API 客户端的请求体与错误提取。
- 创建/关联弹窗中 IMA 的模式归属、专用字段、列表选择、手填 ID、状态失效和连接门禁。

人工与真实 smoke test：

- 使用用户授权的本地凭据读取知识库列表。
- 对选定知识库执行一次 `search_knowledge`，确认获得非空或结构正确的只读检索响应。
- 在本地 Web 界面完成验证、选择和连接交互；测试数据使用隔离的数据目录，完成后不保留真实凭据。
- 确认 IMA 页面不再出现文件上传控件，环境检查不再返回 HTTP 500。

## 验收标准

- 用户无需自行查找内部 Knowledge Base ID 即可选择并连接 IMA 知识库。
- 高级手填 ID 流程仍可工作，并在连接前完成验证。
- DeepTutor 能用 IMA 命中文档片段完成只读检索式问答。
- IMA 不出现在上传型“新建”流程中。
- IMA 环境检查稳定返回说明性结果。
- 所有相关自动化测试通过，真实 smoke test 不泄露或持久化测试凭据。
