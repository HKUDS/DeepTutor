## Supported capabilities

Capability names, module ids, and requirements come from `deeptutor/modules/manifests/`. The “What it does” column is a short guide to that manifest. Optional modules are noted in the sentence, not in **Also needs**.

| Capability | Module | Also needs | What it does | Read |
| --- | --- | --- | --- | --- |
| `chat` | `core` | — | Everyday agent loop with tools | [Chat](/explore/chat-workspace/) |
| `ask_questions` | `core` | — | Asks for missing context, then finishes the request | [Chat](/explore/chat-workspace/) |
| `deep_solve` | `solve` | — | Multi-step worked solutions, including photo problems | [Chat](/explore/chat-workspace/) |
| `deep_question` | `questions` | `parsing` | Generates a practice set from a topic or a source | [Practice](/explore/practice/) |
| `deep_research` | `research` | — | Cited research report. The knowledge module is optional | [Chat](/explore/chat-workspace/) |
| `visualize` | `visualize` | — | SVG, Mermaid, Chart.js, or HTML. The Manim renderer is optional | [Chat](/explore/chat-workspace/) |
| `math_animator` | `renderer-manim` | — | Manim math video or storyboard | [Chat](/explore/chat-workspace/) |
| `mastery_path` | `mastery` | `knowledge` | Adaptive path with a per-topic mastery gate | [Mastery Path](/explore/mastery-path/) |
| `immersive_reading` | `reading` | `knowledge`, `parsing`, `mastery`, `notebook` | Reading beside the thread, with citations back to the source | [Reading](/explore/reading/) |
| `video_lesson` | `video-lesson` | — | Browser lesson with captions and optional narration | [Chat](/explore/chat-workspace/) |
