DeepTutor brings conversations, source materials, learning activities, and reusable assistance into one application. Start with a **workspace** for a subject, project, or learning goal. Its **Home**, **Learning**, and **Resources** shelves hold that workspace’s work. **Partners** and **Personalization** belong to your account and remain available when you switch workspaces.

## Learn through a connected workflow

A useful first project is small: one topic, one source, and one question you want to answer. [The product guide](/explore/) follows that work across the five shelves, explaining when to attach context, when to save an original source, and when to turn it into a structured learning activity.

For example, create a signal-processing workspace, add a short primer to Knowledge Center, ask Home to explain sampling with references, save useful passages to Favorites, and organize your own explanation in a Learning notebook. Then start a Mastery Path or Practice session to test what you retained. A reusable research persona or Partner can help with the same process in a different workspace without merging the projects’ materials.

## Configure only what you need

[Providers](/get-started/providers/) explains model and embedding configuration. [Settings](/explore/settings/) covers interface preferences, services, modules, and readiness. Features depend on installed and enabled modules; a core-only installation has fewer entries than the full application shown in the guides.

For a shared deployment, read [Multi-user setup](/get-started/multi-user/) before inviting learners. An account-level asset is shared across **your own workspaces**, not automatically with every account on the server.
