Start here when you already have the material: a lecture note, a saved passage, or a paper you are reading. You attach it to one question, so the reply can point at a passage you open yourself.

<aside class="dt-prereq">
<p class="dt-prereq-title">Before you begin</p>
<p>Open the app and connect one language model. If this computer does not have that yet, start from the <a href="/get-started/desktop/">desktop quickstart</a>.</p>
</aside>

![Attach a primer and ask for a citation](/gifs/learn-ask-with-source.gif)

The clip opens **Resources** and types the question. It stops before you send. Continue with the steps below.

## 1. Open a new chat in the project workspace

Select this project's workspace. Open **Home → Chat** and start a new chat.

The composer is empty, and the name at the top of the sidebar is the workspace you selected.

## 2. Attach one source

Open **Resources** (`+`) and attach one PDF or one saved record.

The file is listed on the message you are about to send.

## 3. Ask a question that needs a citation

Send: “Explain why low sampling rates can make two different signals look identical; cite this primer.”

The message is in the thread, and the file is still on it.

## 4. Read the reply

Wait for the reply, and read it before you open the file.

The reply names at least one passage in the file you attached.

## 5. Open one cited source

Open that citation and compare it with the sentence that used it.

The passage opens. This lesson ends when the reply is in the thread and you have checked one source yourself.
