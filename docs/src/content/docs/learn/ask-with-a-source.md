You study from a PDF or a saved record you already have. You attach that source and ask about it. The reply points back to it. You can check the answer against your own material instead of trusting a general reply you cannot trace. Choose this for a lecture note, a saved passage, or a paper you are reading. You leave with the reply in the thread and one source you opened.

<aside class="dt-prereq">
<p class="dt-prereq-title">Before you begin</p>
<p>Open the app and connect one language model. If this computer does not have that yet, start from the <a href="/get-started/desktop/">desktop quickstart</a>.</p>
</aside>

## 1. Open a new chat in the project workspace

Select the workspace for this project. Open **Home → Chat** and start a new chat.

The composer is empty, and the workspace name is the project you selected.

## 2. Attach one source

Use the `+` control and attach one PDF, or one saved record.

The source appears on the message you are about to send.

## 3. Ask a question that needs a citation

Send: “Explain why low sampling rates can make two different signals look identical; cite this primer.”

Your message is in the thread, and the source is still attached to it.

## 4. Read the reply

Wait until a reply is in the thread. Read it before you open a source.

The reply is in the thread, and it includes at least one citation.

## 5. Open one cited source

Open one citation from the reply.

The source opens. Compare it with the sentence that cited it.

You are done when a reply is in the thread and one cited source opens.
