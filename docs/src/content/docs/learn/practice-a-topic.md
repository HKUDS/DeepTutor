Use this lesson after you have read the explanation and want to see what you can answer without it. You ask for a short set, save it in this workspace's question bank, and answer one item from memory before you read the reference answer.

<aside class="dt-prereq">
<p class="dt-prereq-title">Before you begin</p>
<p>Open the app and connect one language model. If this computer does not have that yet, start from the <a href="/get-started/desktop/">desktop quickstart</a>.</p>
</aside>

![Choose Quiz and type a practice request](/gifs/learn-practice-a-topic.gif)

The clip opens **Mode**, chooses **Quiz**, and types the request. **Quiz settings** opens beside the composer. The set itself comes after you send.

## 1. Choose Quiz

In [Chat](/learning-workspace/chat/), open **Mode** and choose **Quiz**. Quiz writes a practice set for this turn.

The message shows **Quiz**, and **Quiz settings** opens beside the composer.

## 2. Ask for one set

Name one topic, or attach a source first and ask for questions from that source. Then send.

A set of questions appears in the thread.

## 3. Save the set

When the questions are usable, save them into this workspace's question bank.

The set is stored there.

## 4. Answer one item

Open **Resources → Question Bank**, select that set, and start practice. Recall the answer before you reveal it.

You see one item. The answer is still hidden.

## 5. Read the reference answer

Open the reference answer. The rating controls are on the same card.

This lesson ends when you have answered one item and seen that answer. The set stays in the bank, so you can open it again from there.
