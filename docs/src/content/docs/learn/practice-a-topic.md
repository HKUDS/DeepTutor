After you study a topic, you find out whether you can still recall it. You ask for a short set of questions and save that set in the question bank. You answer one item from memory before you read the reference answer. Choose this when you have already read the explanation and you want to see what you can answer without it. You leave with one answered item and the set stored in this workspace. You can open that set again from the question bank.

<aside class="dt-prereq">
<p class="dt-prereq-title">Before you begin</p>
<p>Open the app and connect one language model. If this computer does not have that yet, start from the <a href="/get-started/desktop/">desktop quickstart</a>.</p>
</aside>

## 1. Choose Quiz

In [Chat](/learning-workspace/chat/), choose **Quiz**. Quiz writes a practice set from the conversation.

**Quiz** is selected for this turn.

## 2. Ask for one set

Ask for one topic, or attach a source first and ask for a set from that source.

A set of questions appears in the thread.

## 3. Save the set

When the questions look usable, save them into this workspace's question bank.

The set is in this workspace's question bank.

## 4. Answer one item

Open **Resources → Question Bank**, select that set, and start practice. Recall the answer before you look.

You are looking at one item, and the answer is still hidden.

## 5. Read the reference answer

Read the reference answer. The rating controls are on the same card.

You are done when you have answered one item and seen the reference answer.
