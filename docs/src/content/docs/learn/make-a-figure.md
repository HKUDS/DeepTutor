Use this lesson when a relationship is hard to follow in a sentence and you want the shape, the axes, or the comparison in front of you. Visualize turns one description into a figure in the thread. This lesson stops at that still figure.

<aside class="dt-prereq">
<p class="dt-prereq-title">Before you begin</p>
<p>Open the app and connect one language model. If this computer does not have that yet, start from the <a href="/get-started/desktop/">desktop quickstart</a>.</p>
</aside>

![Choose Visualize and ask for a sine wave](/gifs/learn-make-a-figure.gif)

The clip opens **Mode**, chooses **Visualize**, and types the request. **Visualize settings** opens beside the composer. The figure appears after you send.

## 1. Open chat

Open [Chat](/learning-workspace/chat/).

The composer is ready.

## 2. Choose Visualize

Open **Mode** and choose **Visualize**. Visualize turns one description into a figure in the thread.

The message shows **Visualize**, and **Visualize settings** opens beside the composer.

## 3. Ask for one figure

Send: “Draw a sine wave I can read. Label the axes.”

The request is in the thread.

## 4. Read the figure

Wait until the figure renders in the thread. It may be SVG, Mermaid, Chart.js, or HTML.

This lesson ends when that figure is in the thread. You can read it without leaving the chat.
