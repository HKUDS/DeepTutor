One question leaves a report whose sources you can open later. You ask that question in the thread, and the reply comes back as a report with citations. The report stays in the thread, so you can return to the source behind a claim. Choose this when you want the papers or pages to stay with the answer. You leave with the report in the thread and at least one source you opened.

<aside class="dt-prereq">
<p class="dt-prereq-title">Before you begin</p>
<p>Open the app and connect one language model. If this computer does not have that yet, start from the <a href="/get-started/desktop/">desktop quickstart</a>.</p>
</aside>

## 1. Open chat in the project workspace

Open [Chat](/learning-workspace/chat/) in the project workspace.

The composer is ready in that workspace.

## 2. Choose Research

Choose **Research** under **More Capabilities**. A capability is the workflow for this turn. Research investigates a question and returns a cited report.

**Research** is selected for this message.

## 3. Decide where the sources come from

Attach a knowledge base when the sources should come from your library. Otherwise this turn can use the web and preprint search the workspace already allows.

If you attached a knowledge base, its name is on the composer. If you did not, the composer has no knowledge-base chip.

## 4. Ask one question

Send: “What changed in retrieval-augmented generation after 2023? Cite the papers you use, and stop at six.”

Your question is in the thread.

## 5. Wait for the report

Wait until the report is in the thread.

The thread shows a report with citations.

## 6. Open one cited source

Open one cited item before you rely on a claim.

The source opens.

You are done when the thread shows a report with citations.
