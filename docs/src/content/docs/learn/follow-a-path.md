A goal becomes a route, and one waypoint records that you can do it. You name one ability and study a single waypoint on that route. That waypoint keeps the result. Choose this when the topic takes more than one sitting and you want a record of what you can already do. You leave with that waypoint filled in. The progress ring on the path reads the same record.

<aside class="dt-prereq">
<p class="dt-prereq-title">Before you begin</p>
<p>Open the app and connect one language model. If this computer does not have that yet, start from the <a href="/get-started/desktop/">desktop quickstart</a>.</p>
</aside>

## 1. Open Mastery Path

Open **Learning → Mastery Path**.

The page lists this workspace’s topics.

## 2. Write one goal

Create a **New mastery goal**. Write the ability as a sentence you can demonstrate. For example: “I can state the sampling theorem and say when two sampled signals become indistinguishable.”

That sentence is on the form. The title comes from it.

## 3. Add one source

Add one saved record as the source for this goal.

The record is listed on the goal.

## 4. Choose the model

Choose the model for the opening conversation.

The opening conversation will use that model.

## 5. Design the outline with the tutor

Choose **Design the outline with the tutor**. The tutor reads the source, asks what you already know and how much time you have, and drafts the map with you.

The outline appears in that conversation. Change it there before you start studying.

## 6. Study one waypoint

Study one waypoint. Answer the question, then explain the result in your own words.

That waypoint shows a recorded result, and the progress ring is no longer empty.

You are done when that waypoint records a result. The result can be an assessment, or your own statement that you have it. The progress ring uses that record.
