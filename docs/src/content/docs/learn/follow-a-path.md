Use this lesson when a topic takes more than one sitting and you want a record of what you can already do. You name one ability. Later, one waypoint on that path stores the result, and the progress ring reads that same record.

<aside class="dt-prereq">
<p class="dt-prereq-title">Before you begin</p>
<p>Open the app and connect one language model. If this computer does not have that yet, start from the <a href="/get-started/desktop/">desktop quickstart</a>.</p>
</aside>

## 1. Open Mastery Path

Open **Learning → Mastery Path**.

The page lists this workspace's topics. **New topic** is there even when the list is empty.

## 2. Write one goal

Choose **New topic**. The form is titled **New mastery goal**. Write the ability as a sentence you can demonstrate. For example: “I can state the sampling theorem and say when two sampled signals become indistinguishable.”

That sentence is the goal. The path title comes from it.

## 3. Add one source

Open **Choose sources** and add one saved record.

The record is listed on the goal.

## 4. Choose the model

Choose the model for the opening conversation.

That conversation uses the model you chose.

## 5. Design the outline with the tutor

Choose **Design the outline with the tutor**. The tutor reads the source, asks what you already know and how much time you have, and drafts the map with you.

The outline appears in that conversation. Change it there before you start studying.

## 6. Study one waypoint

Study one waypoint. Answer the question, then explain the result in your own words.

The waypoint shows a recorded result, and the progress ring is no longer empty. The result can be an assessment, or your own statement that you have it. This lesson ends when that record is on the waypoint.
