## Generate one set and review it

1. In [Chat](/learning-workspace/chat/), choose **Quiz**. Quiz writes a practice set from the conversation.
2. Ask for one topic, or attach a source first.
3. When the questions look usable, save them into this workspace's question bank.
4. Open **Resources → Question Bank**, select that set, and start practice.
5. Try to recall the answer before you look at it.

You are done when you have answered one question from that set and seen the reference answer.

## Where practice lives

Practice turns questions from your learning activities into reviews you can repeat. Open **Learning → Practice** (`/learning/practice`) for today's reviews. Open **Resources → Question Bank** to organize questions, inspect mistakes, or choose a set by hand. Both use the current workspace's question collection.

## Build a question collection

Questions from supported chat, book, and mastery activities can land in the bank. You can also import your own material.

1. Choose **Import questions** in Practice or Question Bank.
2. Choose **Question Bank** or **Mistakes** as the destination.
3. Download an XLSX or CSV template, or prepare XLSX, CSV, TSV, or JSON. Each row needs a question and a correct answer. Tags help you organize the result. English and Chinese column names both work.
4. Select the file and inspect the preview. A file can hold up to **500 questions and 5 MB**. XLSX reads the active sheet.
5. Fix the rows that report an error, upload again, then choose **Confirm import**. The preview itself saves nothing. A question that is already in the bank is skipped, and its tags are merged onto the existing item.

For example, import 30 definitions tagged `probability` and `chapter-2`, then choose a short set from Question Bank before an exam.

## Complete a review

Open Practice and choose **Start today's review** when questions are due. Try to recall the answer before you check it. Where answer checking is available, submit your attempt. Read the reference answer and the explanation, then rate your recall as it was.

| Rating | Use it when |
| --- | --- |
| **Again** | You need another attempt in this round |
| **Hard** | You needed a hint or struggled |
| **Mastered** | You recalled it and can review again in a few days |
| **Easy** | You knew it confidently |

**Again** returns the question in the same round. A saved rating updates the next due date. A skipped question stays due. At the end, the page reports how many reviews were saved and the next review date. Today's queue puts overdue questions first and works in sets of up to 20. A new mistake comes back the next day.

## Organize and diagnose

In Question Bank, you can read the question, the answer you recorded, the correct answer, and the explanation. Use categories, source, and the mistakes filter to narrow a set, then start practice from the questions you selected. Practice analytics shows the pattern of your reviews. A rating you record is that review. It is separate from an assessed skill.

When nothing is due, the page says you are caught up. You can still choose questions in the bank and practice them by hand. If the collection looks wrong, check the current workspace before you import again.

## Combine practice with the tutor

When you miss the same item again, return to its source chat, or open the material in [Reading](/learning-workspace/reading/). Ask for an explanation, then write your own example in the [Learning notebook](/learning-workspace/notebook/). Use a [Mastery Path](/learning-workspace/mastery/) when you want an assessment of a wider ability. Practice schedules the next time you recall a question. A path records whether you have shown a skill.
