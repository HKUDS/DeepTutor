Practice turns questions from your learning activities into repeatable recall. Open **Learning → Practice** (`/learning/practice`) for today's reviews; open **Resources → Question Bank** to organize questions, inspect mistakes or choose a manual set. Both use the workspace's question collection.

![Practice sessions](/screenshots/dev/practice.png)


## Generate a set

In [Chat](/learning-workspace/chat/), choose **Quiz**. Ask for a set on one topic, or attach a source first. When the set looks right, collect it into this workspace's question bank and review it with the steps below.

## Build a question collection

Questions from supported chat, book and mastery activities can be collected in the bank. You can also import your own material rather than generating everything again.

1. Choose **Import questions** in Practice or Question Bank.
2. Choose **Question Bank** or **Mistakes** as the destination.
3. Download an XLSX or CSV template, or prepare XLSX, CSV, TSV or JSON. Each row needs a question and correct answer; tags help organize the result. English and Chinese column names are supported.
4. Select the file and inspect the preview. Files support up to **500 questions and 5 MB**; XLSX reads the active sheet.
5. Fix reported row errors and upload again, then choose **Confirm import**. Previewing alone saves nothing. Identical imports are skipped and their tags combined with the existing item.

For example, import 30 definitions tagged `probability` and `chapter-2`, then choose a short set from Question Bank before an exam.

## Complete a review

Open Practice and choose **Start today's review** when questions are due. Try to recall the answer before checking it. Where answer checking is available, submit your attempt; inspect the reference answer and explanation, then rate your recall honestly.

| Rating | Use it when |
| --- | --- |
| **Again** | You need another attempt in this round |
| **Hard** | You needed a hint or struggled |
| **Mastered** | You recalled it and can review again in a few days |
| **Easy** | You knew it confidently |

**Again** returns the question in the same round. Saved ratings update the next due date. Skipping leaves the question due. Review completion reports how many reviews were saved and the next review date. Today's queue prioritizes overdue questions and works in sets of up to 20; new mistakes return the next day.

## Organize and diagnose

In Question Bank, inspect the question, your recorded answer, the correct answer and explanation. Use categories, source filters and mistakes filtering to focus a set, then start practice from selected questions. Practice analytics helps you see the review pattern; it does not turn a self-rating into an independently assessed skill.

If there are no questions due, the page shows that you are caught up. You can still choose questions in the bank for manual practice. If the collection looks wrong, check the current workspace before importing again.

## Combine practice with the tutor

When you repeatedly miss an item, return to its source chat or open the relevant material in [Reading](/learning-workspace/reading/). Ask for an explanation and produce your own example in the [Learning notebook](/learning-workspace/notebook/). Use [Mastery Path](/learning-workspace/mastery/) when you need assessment of a broader ability; Practice's recall schedule and a path's mastery gate serve different purposes.
