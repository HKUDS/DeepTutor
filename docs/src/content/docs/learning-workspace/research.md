**Research** (`deep_research`) investigates one question and returns a cited report. Use it when a chat answer is too thin and you want the sources kept with the writing.

## Produce one cited report

1. Open [Chat](/learning-workspace/chat/) in the project workspace.
2. Choose **Research** under **More Capabilities**.
3. Attach a knowledge base when the sources should come from your library. Otherwise the run can use the web and preprint search that the workspace already allows.
4. Ask one question, and say what the report must decide. Example: “What changed in retrieval-augmented generation after 2023? Cite the papers you use, and stop at six.”
5. Wait until the report is in the thread. Open cited items before you rely on a claim.

## File it

Save passages you will quote to [Favorites](/learning-workspace/favorites/). Continue in the [notebook](/learning-workspace/notebook/) when the report should become your own draft. Favorites keep the source; the notebook keeps your writing.
