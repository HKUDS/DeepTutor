Vision Solver is the **Solve** capability working from an image. A capability is the workflow for this turn. The same turn can plan steps, run a check, and, for a geometric figure, call GeoGebra.

## Solve one photo

1. Open [Chat](/learning-workspace/chat/) in the workspace for this subject.
2. In the capability menu, open **More Capabilities** and choose **Solve**.
3. Use **+** and attach one photo of the problem. Crop to the question you want solved.
4. Send: “Solve this. Show each step, then the final answer. Stop and ask if the figure is ambiguous.”
5. Read the steps in the thread. Open Activity if you want the tool trace.

You are done when the thread contains a worked solution you can check against the photo.

## A geometric figure

If the picture is a construction, turn on `geogebra_analysis` under **Settings → Tools** before you send. Solve can then turn the figure into GeoGebra commands. Leave it off for a purely algebraic photo.

## Keep the question

When the solution is worth practicing, collect it into [Questions and practice](/learning-workspace/questions/) and review it later. A [Mastery Path](/learning-workspace/mastery/) is the place to test a wider topic, not this single photo.
