**Resources** is the current [workspace](/learning-workspace/workspaces/)'s reusable material shelf. Open it from the sidebar (`/space`). The Classic layout calls this area **Learning Space**. It holds inputs and saved records that you can bring back into Chat and Learning.

![Resources for the active workspace](/screenshots/dev/resources.png)

## What is on the shelf

| Resource | What it keeps | A useful next step |
| --- | --- | --- |
| **Chat History** | Previous conversations with their organization and source context | Reopen the original thread or reference it in a new turn |
| **[Favorites](/learning-workspace/favorites/)** | Collections of saved original conversations and results | Insert selected records into a Learning notebook page |
| **Learning journal** | Current mission, session handoff and confirmed learning records | Check what you were working toward before resuming |
| **Question Bank** | Questions, answers, explanations and mistakes | Choose a set for [Practice](/learning-workspace/questions/) |
| **[Knowledge Center](/learning-workspace/knowledge/)** | Knowledge bases and retrieval integrations | Attach an available base to a conversation or learning task |

Counts help locate populated resources. Their scope follows the active workspace and resource availability; a failed count does not mean the underlying records disappeared.

## Start a reusable study library

1. Select the workspace for your subject.
2. Add source documents to a knowledge base if you want reusable retrieval, or use Reading when you want the original document beside the conversation.
3. Work in Chat, Reading, Books or Mastery Path and save useful results to Favorites.
4. Open the [Learning notebook](/learning-workspace/notebook/) from **Home** to write your own notes, inserting favorites and source links as needed.
5. Return to Question Bank for organization and Practice for scheduled recall.

For example, keep lecture PDFs in a `Signals` knowledge base, clear explanations in a Favorites collection, and your own derivations in notebook pages. These assets can work together without being interchangeable.

## Reopen and organize conversations

Chat History lets you search, filter, rename, pin, archive, restore and delete conversations. Little Tutor threads remain nested under the source conversation. A learning conversation reopens in its original study surface, such as its path or reading collection, so the accompanying context is restored. Archiving is useful for hiding completed work; permanent deletion is a separate action.

## Resources and account personalization

**Partners** and **Personalization** have their own account-level areas. My Agents, Personas, Skills, MCP Services, CLI Apps and Memory live under Personalization, so they remain available as you switch workspaces. A workspace can assign a subset of supported shared resources without moving those account settings into its library.

A persona changes how the assistant behaves; a knowledge base supplies source material; a favorite preserves a result; a notebook page records your own synthesis; memory carries inspectable personalization. Choose the right kind when reusing information.

Some optional deployments show extra resource tiles only when the corresponding capability is installed. Features and access can also be limited by the account's learning policy.
