These entries summarize what a person using DeepTutor notices. Names and dates follow [`assets/releases/`](https://github.com/HKUDS/DeepTutor/tree/dev/assets/releases). Full notes and older versions are on [GitHub Releases](https://github.com/HKUDS/DeepTutor/releases).

## v1.7.4 — 2026-11-20

Desktop security update for macOS and Windows. The app verifies runtime updates with a new public key. A saved runtime signed with the retired key is replaced by the runtime bundled in this app, after a workspace backup.

Install the v1.7.4 app itself. Earlier desktop versions still trust the retired key. [Release notes](https://github.com/HKUDS/DeepTutor/blob/v1.7.4/assets/releases/ver1-7-4.md) · [v1.7.4](https://github.com/HKUDS/DeepTutor/releases/tag/v1.7.4)

## v1.7.3 — 2026-11-16

Reading gains continuous zoom and more reliable annotations. Book edits can be reviewed as a diff before they apply. Search adds DeepSeek, SpecStream, and SearchApi. A configured Agent Client Protocol process can be consulted as a local subagent. Practice and mastery keep more of their context. Installing a newer desktop app trials its bundled core and can roll back.

[Release](https://github.com/HKUDS/DeepTutor/releases/tag/v1.7.3)

## v1.7.2 — 2026-11-06

GitHub Releases include Apple silicon and Intel Mac installers plus the Windows installer and portable ZIP. Selected text can be read aloud. Model setup, mastery, retrieval, and updates are more reliable.

[Release](https://github.com/HKUDS/DeepTutor/releases/tag/v1.7.2)

## v1.7.1 — 2026-11-01

First Open DeepTutor desktop previews for Apple silicon, Intel, and Windows. More interface languages, password changes, checked video lessons, and additional providers. Existing runtime data stays in place.

[Release](https://github.com/HKUDS/DeepTutor/releases/tag/v1.7.1)

## v1.7.0 — 2026-10-28

Modular installation: `deeptutor[full]` is the web app, and `deeptutor` is the core CLI and SDK. The learning workspace, block notebooks with Dito, and narrated video lessons ship in this version. Full-app upgrades keep the existing runtime home.

[Release](https://github.com/HKUDS/DeepTutor/releases/tag/v1.7.0)
