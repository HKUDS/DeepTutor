**Visualize** turns one description into a figure in the thread. Core results are SVG, Mermaid, Mermaid mind maps, Chart.js, and interactive HTML.

## Make one figure

1. Open [Chat](/learning-workspace/chat/).
2. Choose **Visualize** in the capability menu.
3. Name the figure and the claim it must show. Example: “A Chart.js line chart of sampling rate against aliasing, with the Nyquist rate marked. No 3D.”
4. Wait until the figure renders in the thread. If the type is wrong, reply with the type you wanted (SVG, Mermaid, or Chart.js) and ask for a replacement.

The figure is done when you can read the claim off the picture without the surrounding prose.

Manim animation and storyboard are also render modes of this capability. For a derivation you want to watch, use [Math Animator](/multimodal-studio/math-animator/). GeoGebra is an optional install, not one of the core types.
