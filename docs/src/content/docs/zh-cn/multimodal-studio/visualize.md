**Visualize** 把一段描述变成线程里的一张图。核心结果是 SVG、Mermaid、Mermaid 思维导图、Chart.js 和可交互 HTML。

## 做一张图

1. 打开[对话](/zh-cn/learning-workspace/chat/)。
2. 在能力菜单里选择 **Visualize**。
3. 写明图要表达的判断。例如：“用 Chart.js 画采样率与混叠的折线，标出奈奎斯特率。不要 3D。”
4. 等到图出现在线程里。类型不对时，直接回复你要的类型（SVG、Mermaid 或 Chart.js），要求重做一张。

你不看旁边的文字也能从这张图读出那个判断，这张图就完成了。

Manim 动画和分镜也是这个能力的渲染模式。推导需要被看的过程时，用[数学动画](/zh-cn/multimodal-studio/math-animator/)。GeoGebra 是可选安装，不属于核心类型。
