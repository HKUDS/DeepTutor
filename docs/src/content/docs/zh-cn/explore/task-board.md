从**主页 → 任务看板**（`/kanban`）整理当前工作区任务。它适合“尝试五道积分题”“总结第四章”等具体行动；相应书籍、路径和阅读活动则保留在学习区域。

![任务看板](/screenshots/dev/task-board.png)

## 规划与更新任务

1. 输入任务标题并添加到看板。
2. 打开卡片，编辑标题、备注与可选截止日期。
3. 在待办、进行中、已完成列之间推进；可以拖动卡片，也可使用卡片的移动按钮。
4. 用**今天**或**本周**按日期缩小范围。
5. 完成后可归档，清理当前视图；需要时从归档视图恢复。

截止日期显示在卡片上，未完成的逾期任务会被突出显示。卡片还可以显示关联的日历时间块数量。打开[日历](/zh-cn/explore/calendar/)为工作安排时间；截止日期与预留学习时段不同，设置截止日期本身并不意味着已经安排执行时段。

## 一套复习看板

新建“阅读条件概率证明”“写自己的例子”“完成今日复习”三个任务。阅读合集、笔记页面和练习会话仍在各自学习界面，看板只记录下一步行动。完成后逐个推进卡片，考试结束再归档。

看板跟随当前[工作区](/zh-cn/explore/workspaces/)；从 `概率论` 切到 `研究项目` 时，会展示后者的任务。日历事件仍属于账号级，同时叠加工作区任务与学习信息。
