**个性化（Personalization）**是账号的行为预设与连接资源架。从侧栏进入，可以打开**子智能体、Personas、技能、MCP 服务、CLI 应用、记忆**。从课程工作区切换到研究工作区后，这些入口仍然存在；每个工作区再决定自己的对话可以使用哪些资源。

![个性化](/screenshots/dev/personalization.png)

## 账号资源架与工作区上下文

工作区组织实际的工作：**主页**承载对话，**学习**承载阅读与练习，**资源**承载材料。个性化提供处理这些材料的方式。例如，同一个耐心教学人格可以用于微积分和外语课程；两个课程仍分别保留自己的文件、阅读进度与学习主题。

| 放在这里的内容 | 用途 | 需要记住的范围 |
| --- | --- | --- |
| **子智能体** | 请教连接的 agent 或 Partner；导入过去的 agent 会话 | 连接属于账号；本机 agent 使用自己配置的工作目录 |
| **Personas** | 复用语气、教学方式、回答规则 | 账号级行为预设，在对话中选择 |
| **技能** | 复用工作流及配套说明 | 账号共享技能库，或明确选择的工作区技能库 |
| **MCP 服务** | 授权外部服务并发现其工具 | 账号连接，以及获准使用的部署级服务 |
| **CLI 应用** | 通过工具运行已安装的命令行程序 | 管理员安装，账号授权决定使用范围 |
| **记忆** | 查看保留的偏好与学习经历 | 个人记忆随学习者保留；Partner 关系记忆另行管理 |

进入资源库不等于在所有工作区自动获得使用权限。在**设置 → 工作区**中配置允许的技能、MCP 服务和知识库；对话还可以在输入框中进一步缩小技能与 MCP 服务范围。这些选择与当前用户的授权取交集，不会授予其他账号资源的访问权。输入框未做选择时继承工作区设置。配置见[设置](/zh-cn/explore/settings/)，材料管理见[资源](/zh-cn/explore/space/)。

## 创建并使用人格

打开**个性化 → Personas**，创建预设，填写名字、简短说明和 Markdown 指令。尽量描述具体行为，例如「先问学习者的下一步思路，再揭示解法」。保存后在聊天输入框的人格控件中选中，用一个简短问题测试。

人格影响回答方式；当前能力仍决定任务与阶段。教师人格可以引导解释，研究助手人格可以引导文献讨论，而不替代能力本身的流程。风格需要调整时编辑自己的预设；不再需要时删除。普通用户看到的部署预设只读；自己的同名人格优先于部署预设。

创建 Partner 时，也可以用人格作为灵魂的起点。向导会复制内容，形成 Partner 自己的身份；以后修改原人格，不会自动改写这个 Partner。需要持续陪伴、渠道与关系记忆时，使用[伙伴](/zh-cn/explore/partners/)。

## 建立可复用技能库

打开**个性化 → 技能**，在创建或导入前先确认 **Skill library（技能库）**。**Account shared skills（账号共享技能）**可以分配给多个工作区；选择某个工作区后，管理的是该工作区的本地技能。启用的工作区同名技能优先于共享版本，因此课程专用流程可以独立演进。

适合做成技能的任务包括按评分表审阅作文、把实验记录整理成报告等重复流程。写清触发条件、输入、步骤、输出要求。通过 EduHub 导入社区技能后，先检查指令，再用一个小型真实案例测试。账号版本保留通用流程，课程有不同评分表时再写工作区覆盖版本。详见[技能](/zh-cn/ecosystem/skills/)。

## 连接服务与应用

需要远程服务时使用 **MCP 服务**。从商店连接，或添加服务器 URL，完成 API key / OAuth 流程，确认连接成功；再把它加入目标工作区的允许范围，按需在对话中选中。如果状态变为 **needs auth**，从 Installed 重新授权。删除连接后工具不可用，也应检查仍引用它的工作区。凭据跟随账号连接保存，不放进工作区文件。

需要程序处理文件时使用 **CLI 应用**。管理员安装应用并授予使用权，智能体在沙箱中运行它。技能可以说明何时、如何使用应用，但导入技能不会安装程序，也不会获得程序的执行授权。详见 [MCP 服务](/zh-cn/ecosystem/mcp/)和 [CLI 应用](/zh-cn/ecosystem/cli-apps/)。

## 组合使用

做文献项目时，在项目**资源**中保留 PDF 与笔记，在**学习**中阅读和标注，再回到**主页**选择研究人格与允许使用的引用技能。任务需要实时查询时，再加入已连接的服务。生成内容与会话上下文仍关联当前工作的工作区。

准备考试时，用课程工作区的材料和学习主题搭配教学人格。把通用复习规划技能放在账号共享库，把课程评分规则放在工作区技能库。辅导风格不再适合你时，也可以到**记忆**检查保存了哪些偏好。

需要在 IM 中随时联系同伴时，创建账号级 Partner，并选择私有复制资料库或绑定实时工作区。还可以通过子智能体从主页请教它。渠道、资料范围和会话连续性是不同的设置，分别控制在哪里联系、能看到什么、继续哪一段对话。

## 找不到资源时

先检查账号库，再检查工作区允许范围，最后检查对话选择。共享部署还需要检查用户授权。技能可能存在但被工作区过滤；MCP 服务可能已选中但需要重新授权；CLI 应用可能列在目录里却尚未安装、启用或分配。**设置 → 运行状态**可以帮助区分模块、模型缺失与资源选择问题。
