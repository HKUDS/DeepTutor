练习把学习活动中的题目变成可重复的回忆训练。从**学习 → 练习**（`/learning/practice`）进入今日复习；从**资料 → 题库**整理题目、查看错题或手选题组。两者使用当前工作区的题目集合。

![练习会话](/screenshots/dev/practice.png)

## 建立题目集合

受支持的聊天、书籍和精通之路活动产生的题目可以汇入题库。也能导入自己的材料，无需全部重新生成。

1. 在练习或题库中选择**导入题目**。
2. 选择导入**题库**或**错题**。
3. 下载 XLSX 或 CSV 模板，也可自行准备 XLSX、CSV、TSV 或 JSON。每行必须含题目与正确答案；标签可辅助整理。支持中英文列名。
4. 上传并检查预览。每个文件最多 **500 题、5 MB**；XLSX 读取当前活动工作表。
5. 修正报错行后重新上传，再点击**确认导入**。预览本身不会保存；重复导入的相同题目会跳过，标签合并到已有题目。

例如，将 30 个定义打上 `概率论` 与 `第二章` 标签导入，考前在题库选一个短题组。

## 完成一次复习

有到期题目时，打开练习并选择**开始今日复习**。先回忆，再查看答案。支持答案检查时可提交作答；看完参考答案与解析后，如实评价回忆情况。

| 评级 | 适用情况 |
| --- | --- |
| **重来（Again）** | 需要在本轮再次尝试 |
| **困难（Hard）** | 需要提示或回忆吃力 |
| **已掌握（Mastered）** | 能回忆出来，过几天再复习 |
| **简单（Easy）** | 确信自己熟悉答案 |

**重来**会在本轮再次出现；保存评级会更新下次到期日。跳过的题目仍处于待复习状态。结束时会显示已保存的复习次数与下一次日期。今日队列优先安排逾期题，每组最多 20 题；新错题会在次日回来。

## 整理与诊断

题库中可查看题目、已记录作答、正确答案与解析。使用分类、来源和错题筛选缩小范围，再选题练习。练习分析帮助你观察复习模式，但自主评级不等于独立评估后的能力证明。

没有到期题时，页面会提示已完成当前复习；仍可从题库手选题目练习。集合内容不对时，先检查当前工作区，再决定是否重新导入。

## 与导师衔接

同一题反复出错时，返回来源对话，或在[阅读](/zh-cn/explore/reading/)中打开相应材料。请助手解释，再到[学习笔记本](/zh-cn/explore/co-writer/)写一个自己的例子。需要评估更完整的能力时使用[精通之路](/zh-cn/explore/mastery-path/)；练习的回忆日程与路径的掌握门槛用途不同。
