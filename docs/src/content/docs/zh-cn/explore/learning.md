**学习**是当前工作区的学习区域。从侧栏进入，可新建学习活动、搜索已有记录或接着上次的位置继续。经典布局中该区域称为**个性化学习**。

![一个工作区中的学习活动](/screenshots/dev/learning.png)

## 选择学习方式

| 活动 | 从什么开始 | 保留什么 |
| --- | --- | --- |
| [书籍](/zh-cn/explore/book/) | 一个主题和可选来源材料 | 可修改的章节计划、生成页面、阅读位置与页面对话 |
| [精通之路](/zh-cn/explore/mastery-path/) | 描述目标能力的学习目标 | 知识点地图、主题对话与掌握依据 |
| [练习](/zh-cn/explore/practice/) | 已收集或导入的题目 | 作答、错题、回忆评级与下次复习日期 |
| [沉浸式阅读](/zh-cn/explore/reading/) | 文档、网页、视频或音频 | 材料合集、来源关联对话、高亮与笔记 |

书籍提供连贯读物；精通之路跟踪能力；练习训练回忆；沉浸式阅读紧贴已有来源。先选择适合眼前任务的方式，再按需要衔接其他功能。

## 开始与继续

1. 检查当前[工作区](/zh-cn/explore/workspaces/)。
2. 使用学习页的新建控件或侧栏的新建学习入口，选择方式并填写主题、目标或材料。
3. 从**全部学习**或对应功能资料库重开生成的记录。
4. 记录增多后，按活动类型筛选或按标题搜索；**显示更多**可展开更早记录。

概览按最近更新排列活动。书籍展示阅读进度，路径展示已掌握知识点。**需要你关注的事项**列出到期的路径复习，以及编译中或暂停的书籍；暂停的书籍需要检查，不能当成已完成。一类记录加载失败时可重试，概览不完整不代表记录已删除。

## 从一个章节走向长期掌握

准备概率论考试时，将课件 PDF 导入阅读，询问难懂证明；再用明确后的目标创建精通之路。把精炼解释存到收藏夹，插入学习笔记本，并写上自己的例题。第二天到练习复习收集的题目。如果需要整门课的连贯讲解，也可生成一本书。

[资料](/zh-cn/explore/space/)保存可复用输入与学习结果；**学习日志**记录当前目标、上次会话交接和已确认学习记录，与各项活动自身的进度互补。

## 权限与范围

可用活动取决于部署中安装的模块、配置的模型以及账号权限。被锁定或缺失的功能可能需要管理员授权或安装模块。学习记录属于当前工作区，切换后资料库会变化；伙伴与个性化可跨工作区使用。共享部署由管理员管理模型目录，用户授权决定模型访问范围。
