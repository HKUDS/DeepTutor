侧栏说明的是**内容属于哪里**。先选择工作区，再在其中的对话、学习活动与来源材料之间切换；你的账户则提供可带入这些工作的伙伴和个性化能力。

## 两种范围，五个入口

| 入口 | 范围 | 用途 |
| --- | --- | --- |
| [对话](/zh-cn/explore/chat-workspace/) | 工作区 | 对话、任务看板、学习笔记本 |
| [学习](/zh-cn/explore/learning/) | 工作区 | 书籍、精通之路、阅读集合、练习 |
| [资料](/zh-cn/explore/space/) | 工作区 | 聊天记录、收藏夹、题库、学习日志、知识库 |
| [伙伴](/zh-cn/explore/partners/) | 账户 | 持久伙伴的指令、资源访问与渠道 |
| [个性化](/zh-cn/explore/personalization/) | 账户 | 角色、技能、外部智能体、MCP、CLI 应用与记忆控制 |

**日历是主页中的一个例外**：它提供跨工作区的账户视图，[日历指南](/zh-cn/explore/calendar/)会说明如何辨认事件的来源工作区。伙伴也有明确的工作上下文：身份属于账户，不代表任意对话都能读取所有工作区。

## 1. 给项目一个独立工作区

为“信号与采样”建立或选择工作区，把讲义和练习与“学术写作”等项目分开。添加材料、开始学习活动前，先检查当前工作区。切换后，前三个入口的内容随之变化，伙伴与个性化库仍然可用。详见[工作区与切换](/zh-cn/explore/workspaces/)。

## 2. 先带入来源，再提出具体问题

把可复用材料加入[知识库](/zh-cn/explore/knowledge/)；如果想对照原文学习，也可以在[阅读](/zh-cn/explore/reading/)中打开具体文档。回到主页附加相关上下文，提出明确问题，例如：“结合这份讲义说明，为什么采样率过低会让两个不同的信号看起来相同？请给出来源。”

保存过的资产不会自动进入每一次模型请求。应主动附加来源或选择支持的学习上下文，并在继续推导前核对引用段落。

## 3. 将证据与自己的理解分开保存

把有用的原文保存到[收藏夹](/zh-cn/explore/favorites/)，再在[学习笔记本](/zh-cn/explore/co-writer/)中写出自己的解释，按需插入引用。笔记本用于发展理解，收藏夹用于保留以后还能复用的来源。对某个结论有疑问时回到原文；需要改进段落时，在旁边调用 Dito 讨论。

## 4. 选择适合目标的学习方式

- [书籍](/zh-cn/explore/book/)：按页面和交互块组织系统内容。
- [精通之路](/zh-cn/explore/mastery-path/)：将目标拆成主题，并沿路径学习。
- [阅读](/zh-cn/explore/reading/)：围绕原文或媒体时间点提问。
- [练习](/zh-cn/explore/practice/)：作答、检查反馈、复习薄弱环节。

它们是不同的学习方式，不是必须依次完成的步骤。从一种开始，使用界面支持的保存与附加操作，把产出带入下一次活动。

## 5. 复用助手，不混合项目

选择一个要求你解释推理的角色；需要固定方法时，附加相关技能；需要第二种视角时连接外部智能体，或为伙伴设定角色与资源范围。这些账户资产可在另一个工作区继续使用，而每个工作区保留自己的材料与学习记录。

## 下次从哪里继续

用主页的[任务看板](/zh-cn/explore/task-board/)记录下一步，到[资料](/zh-cn/explore/space/)查找证据与历史，在学习列表中重新打开活动。切换科目时，不必重新安装应用或再创建一遍伙伴。
