从**主页 → 日历**（`/calendar`）查看日期和学习安排。虽然入口在主页，**日历与事件属于账号级**；叠加层展示当前工作区的任务、到期复习、定时指令和活动足迹。切换工作区时，这些层会变化，个人事件仍保留。

![日历](/screenshots/dev/calendar.png)

## 添加学习日程

1. 打开日历中的日期或时段并创建事件。
2. 填写标题、开始与结束时间，选择是否为全天事件。
3. 选择所属日历，并按需设置地点、备注、重复规则和提醒时间。
4. 保存后可重开检查和修改；重复事件可在支持的操作中选择修改本次、后续或整个系列。

使用不同日历与颜色区分课程、个人安排和学习时段。月视图、时间网格和日程列表适合不同尺度的规划。提醒设置记录期望提醒的时间，实际送达取决于可用的通知与运行环境配置。

## 理解工作区叠加层

| 图层 | 含义 |
| --- | --- |
| 任务 | 当前工作区任务看板的截止日期，以及已有的关联时间块 |
| 复习 | 某天到期的精通之路与练习复习 |
| 自动任务 | 对话定时指令及预计运行时间 |
| 足迹 | 已发生的对话、练习复习与掌握证据 |

可切换图层减少干扰。定时指令与普通事件不同：它会让助手稍后在所属对话运行。到期复习仍需要你打开对应学习活动并完成。

## 规划一周

将课程存入账号日历。在 `概率论` 工作区添加周五到期的任务，为周三预留学习事件，并在选时段前查看到期复习层。切换到另一个工作区后，周三事件仍可见，任务与学习图层则转为那个项目的内容。

参见[任务看板](/zh-cn/explore/task-board/)、[练习](/zh-cn/explore/practice/)与[工作区](/zh-cn/explore/workspaces/)。
