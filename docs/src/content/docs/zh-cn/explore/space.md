**资料**是当前[工作区](/zh-cn/explore/workspaces/)可复用材料的入口，从侧栏打开（`/space`）。经典布局称其为**学习空间（Learning Space）**。这里保存可带回聊天和学习活动的输入与记录。

![当前工作区的资料](/screenshots/dev/resources.png)

## 这里有什么

| 资料 | 保存什么 | 下一步怎么用 |
| --- | --- | --- |
| **聊天历史** | 历史对话、组织方式与来源上下文 | 重开原对话，或在新轮次引用 |
| **[收藏夹](/zh-cn/explore/favorites/)** | 收藏的原始对话和结果集合 | 把选中记录插入学习笔记本页面 |
| **学习日志** | 当前目标、会话交接与已确认学习记录 | 继续之前先回顾目标 |
| **题库** | 题目、作答、解析与错题 | 选一组进入[练习](/zh-cn/explore/practice/) |
| **[知识中心](/zh-cn/explore/knowledge/)** | 知识库与检索集成 | 将可用知识库挂载到对话或学习任务 |

计数帮助你找到已有内容。范围随当前工作区和资源可用性变化；计数加载失败不代表底层记录消失。

## 建立可复用的学习资料库

1. 选择对应学科的工作区。
2. 需要反复检索时，把来源文档加入知识库；需要对照原文讨论时使用阅读。
3. 在聊天、阅读、书籍或精通之路中学习，并将有用结果存到收藏夹。
4. 从**主页**打开[学习笔记本](/zh-cn/explore/co-writer/)，撰写自己的笔记，按需插入收藏与来源链接。
5. 回到题库整理题目，到练习进行有日程的主动回忆。

例如，讲义 PDF 放入 `信号` 知识库，清楚的解释放入收藏集合，自己的推导写入笔记页面。它们相互配合，但用途不同。

## 重开与整理对话

聊天历史支持搜索、筛选、重命名、置顶、归档、恢复与删除。Little Tutor 保持嵌套在来源对话下；学习对话会重回所属路径或阅读合集等原学习界面，以恢复配套上下文。归档适合收起已完成内容，永久删除是另一项操作。

## 资料与账号个性化

**伙伴**与**个性化**各有账号级区域。子智能体、人设、技能、MCP 服务、CLI 应用和记忆位于个性化下，切换工作区后仍可使用。工作区可以分配受支持共享资源的子集，而不是将账号设置搬进自身资料库。

人设改变助手的行为，知识库提供来源，收藏保留结果，笔记页面记录自己的综合理解，记忆承载可检查的个性化。复用信息时按目的选择。

部分可选部署只在安装相应能力后显示额外资料卡片；账号学习策略也可能限制功能与权限。
