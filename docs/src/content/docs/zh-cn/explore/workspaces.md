工作区是一个学科或项目的容器。先选择工作区，再进入**主页、学习、资料**：这三个区域展示当前工作区的内容。工作区比一段对话、一个阅读合集都更高一层。

![从侧栏切换工作区](/screenshots/dev/workspace-switcher.png)

## 理解层级

| 层级 | 包含什么 | 示例 |
| --- | --- | --- |
| 工作区 | 对话、学习活动、保存的资料、工作文件、指令和资源分配 | 概率论期末备考 |
| 主页 | 聊天、任务看板、学习笔记本；日历是账号级例外 | 提问、安排复习、整理笔记 |
| 学习 | 书籍、精通之路、练习、沉浸式阅读 | 阅读第三章并复习条件概率 |
| 资料 | 聊天历史、收藏夹、学习日志、题库、知识中心 | 复用解释、查找来源 |
| 账号 | 伙伴、个性化以及共用设置 | 复用人设、连接的智能体或模型配置 |

切换工作区会改变前三个区域的内容。伙伴与个性化跟随账号，可以跨工作区复用；一本书属于创建它的工作区。资源分配控制工作区能使用哪些技能、MCP 服务和知识库。

## 创建第一个工作区

1. 点击侧栏顶部的工作区名称，选择**管理工作区**，或打开**设置 → 工作区**。
2. 选择**新建工作区**，输入有辨识度的名称，例如 `概率论——秋季考试`。
3. 可选填已有文件夹路径；留空则在配置的工作区根目录下创建存储。服务器部署中的路径指服务器文件夹。
4. 填写**工作区指令**并选择**分配的资源**。例如：“用中文解释，保留数学符号，先让我尝试，再给解答。”
5. 创建后，从工作区菜单选中它，再开始对话或学习活动。

指令与资源修改从后续支持的轮次生效。它们在能力自身规则内引导助手，不会启用未安装工具，也不会绕过权限。

## 切换与继续

在工作区菜单中选择另一个工作区。顶层页面会进入目标工作区的同类页面；记录详情页会返回对应功能列表，因为具体记录属于原工作区。账号级页面仍可使用。浏览器会记住工作区，链接也可以明确指定工作区。

切换后列表看似为空时，先检查工作区名称。新建工作区不会自动复制已有书籍、对话或学习进度。

## 文件与生成内容

将来源文件放进工作区文件夹，供助手读取。生成文件存入 `outputs/` 下按轮次划分的目录，助手可展示供打开或下载的文件；要导出到内容文件夹的其他位置，需要对具体来源和目标授权，因此生成报告不会悄悄覆盖原始资料。

**通用工作区**承接未选择自定义工作区的内容；**系统工作区**保存共享技能和脱敏配置快照，密钥与令牌仍放在私有配置中。

## 管理已有工作区

设置中可重命名自定义工作区、修改指令与资源分配、归档或恢复。**归档**会保留对话和文件。**移动文件夹**会先复制并校验再切换存储，保持工作区身份和对话绑定不变，并保留旧目录作为备份。更换存储根目录前，应先结束正在运行的对话。

## 一套实际学习流程

创建 `信号与系统`，放入课件并分配对应知识库。在[主页](/zh-cn/explore/chat-workspace/)询问简短解释，到[沉浸式阅读](/zh-cn/explore/reading/)打开原文，为目标技能创建[精通之路](/zh-cn/explore/mastery-path/)。把有用回答存到[收藏夹](/zh-cn/explore/favorites/)，在[学习笔记本](/zh-cn/explore/co-writer/)写自己的总结，再用[练习](/zh-cn/explore/practice/)进行每日回忆。这些内容始终围绕同一工作区组织。
