**收藏夹**保存你想留下的材料：有用对话、解释、研究结果及其他受支持的学习输出。从**资料 → 收藏夹**（`/notebooks`）进入，创建或选择一个集合，再打开其中记录。

收藏夹与**学习笔记本**分工不同：前者保存来源记录；位于 `/co-writer` 的笔记本供你撰写和组织自己的页面。部分保存控件与旧集成仍将收藏集合称为 **Notebook（笔记本）**。

![收藏夹保留来源原文](/screenshots/dev/favorites.png)

## 保存值得留下的内容

1. 在支持的对话或结果中使用保存或收藏操作。
2. 选择目标集合，或为某个主题创建集合，例如 `傅里叶——例题`。
3. 打开收藏夹，检查存储的标题、正文与来源信息。
4. 按集合整理记录；主题结构变化时可移动或复制记录，也可将整个集合导出为 Markdown。

收藏记录是已保存材料。打开记录不会发起新生成，也不会修改来源存档。展示方式随内容变化：对话保留发言人结构，题目可展开答案，长文章可显示目录，受支持媒体可直接播放。

## 在笔记页面中使用收藏

1. 打开一个[学习笔记本](/zh-cn/explore/co-writer/)页面。
2. 从页面菜单选择**插入收藏**。
3. 搜索**全部收藏**，或按集合和内容类型缩小范围。
4. 预览并选择一条或多条记录，插入顺序与选择顺序一致。
5. 插入原记录，或请 Dito 将选中来源整理为有引用的连贯笔记。

插入的收藏块保留已保存内容与返回收藏记录的链接。应把它视为来源快照，在旁边写自己的理解，而非假定它会跟随原对话的每次修改。收藏记录移动后，稳定链接仍可识别它。

## 一种实用的整理方法

为一个模块建立 `来源`、`例题`、`待复习问题` 三个集合。保存聊天中的清晰解释、研究结果与阅读笔记；在学习笔记本中将相关收藏放到自己的总结旁，再请 Dito 基于这页生成练习题。

收藏夹属于当前工作区的资料。它不会自动变成知识库索引或全局记忆。可在提供该入口的工作流中挂载保存内容、将其插入笔记页面，或在创建支持的学习活动时明确选作来源。

相关流程参见[资料](/zh-cn/explore/space/)、[学习笔记本](/zh-cn/explore/co-writer/)与[知识中心](/zh-cn/explore/knowledge/)。
