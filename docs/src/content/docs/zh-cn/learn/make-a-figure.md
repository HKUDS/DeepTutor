某个关系用一句话很难讲清，你又想把形状、坐标轴或两样东西的对照摆到眼前时，用这一课。可视化会把一段描述画成对话里的一张图。这一课讲的就到这张静止的图为止。

<aside class="dt-prereq">
<p class="dt-prereq-title">开始之前</p>
<p>先打开应用，并接上一个语言模型。这台电脑还没有的话，从<a href="/zh-cn/get-started/desktop/">桌面端</a>接上。</p>
</aside>

![选择可视化并要求画一条正弦曲线](/gifs/learn-make-a-figure.gif)

动图打开**模式**，选择**可视化**，再输入要求。输入框旁会打开**可视化设置**。图要等你发送之后才出现。

## 1. 打开对话

打开[对话](/zh-cn/learning-workspace/chat/)。

输入框已经可以用了。

## 2. 选择可视化

打开**模式**，选择**可视化**。可视化会把一段描述画成对话里的一张图。

消息上会出现**可视化**，输入框旁会打开**可视化设置**。

## 3. 要一张图

发送：“画一条能看清的正弦曲线，标出坐标轴。”

要求会进入对话。

## 4. 看这张图

等到图在对话里画出来。它可能是 SVG、Mermaid、Chart.js 或 HTML。

图出现在对话里，不用离开聊天就能看，这一课就到这里。

![对话里画出的一条正弦曲线](/screenshots/dev/learn-visualize-figure.png)
