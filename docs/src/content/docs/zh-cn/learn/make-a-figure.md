一句话里看不清的关系，适合用这一课。你要的是形状、坐标轴或对照，摆在对话旁边。可视化会把一段描述画成对话里的一张图。这一课只留下这张图。

<aside class="dt-prereq">
<p class="dt-prereq-title">开始之前</p>
<p>先打开应用，并接上一个语言模型。这台电脑还没有的话，从<a href="/zh-cn/get-started/desktop/">桌面端</a>接上。</p>
</aside>

![选择 Visualize 并要求画一条正弦波](/gifs/learn-make-a-figure.gif)

动图在模式里选可视化，再输入要求。旁边会打开可视化设置。图要等你发送之后才会出现。

## 1. 打开对话

打开[对话](/zh-cn/learning-workspace/chat/)。

打开后就能在这里输入。

## 2. 选择可视化

打开**模式**，选择**可视化**。可视化把一段描述画成对话里的一张图。

消息上出现**可视化**，旁边打开**可视化设置**。

## 3. 要一张图

发送：“画一条能读的正弦波，标出坐标轴。”

这条要求进入对话。

## 4. 看这张图

等到图出现在对话里。它可能是 SVG、Mermaid、Chart.js 或 HTML。

图留在这段对话里，不用另开页面。
