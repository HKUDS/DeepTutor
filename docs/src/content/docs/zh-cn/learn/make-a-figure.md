放在一句话里很难跟上的关系，会变成对话里的一张图。你描述这个关系，并请 Visualize 把它画出来。Visualize 是一条流程，把一段描述变成可以在对话里阅读的图。这一课只用 Visualize。你想让形状、坐标轴或对照关系摆在眼前，同时继续看这段对话，就用这一次。做完之后，对话里留下这一张图。

<aside class="dt-prereq">
<p class="dt-prereq-title">开始之前</p>
<p>先打开应用，并接上一个语言模型。这台电脑还没有的话，从<a href="/zh-cn/get-started/desktop/">桌面端</a>接上。</p>
</aside>

## 1. 打开对话

打开[对话](/zh-cn/learning-workspace/chat/)。

输入框可以发送。

## 2. 选择 Visualize

在能力菜单里选择 **Visualize**。能力是这一轮要走的流程。Visualize 把一段描述变成对话里的一张图。

这一轮选中的是 **Visualize**。

## 3. 要一张图

发送：“画一条能读的正弦波，标出坐标轴。”

这条请求已经在对话里。

## 4. 看这张图

等到图出现在对话里。它可能是 SVG、Mermaid、Chart.js 或 HTML。

对话里出现了这张图，这一次就完成了。
