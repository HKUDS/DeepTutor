一个主题要分几次学，又想记下已经能做到的事，就用这一课。你先写下一项能演示的能力。以后路径上的一个路标留着结果，进度环显示的也是这条记录。

<aside class="dt-prereq">
<p class="dt-prereq-title">开始之前</p>
<p>先打开应用，并接上一个语言模型。这台电脑还没有的话，从<a href="/zh-cn/get-started/desktop/">桌面端</a>接上。</p>
</aside>

![打开新的掌握目标并写下这项能力](/gifs/learn-follow-a-path.gif)

动图点**新建精通目标**，写下这项能力，停在**选择资料**之前。

## 1. 打开精通之路

打开**学习 → 精通之路**。

页面列出这个工作区里的主题。列表是空的，也能看到**新建精通目标**。

## 2. 写下一项能力

点**新建精通目标**。用一句你做得到的话写下这项能力，例如：“我能说出采样定理，并说明两个采样后的信号在什么时候分不出来。”

这句话就是目标。路径的标题从它生成。

## 3. 加上一份材料

点**选择资料**，加入一条已保存的记录。

这条记录列在目标上。

## 4. 选定开场用的模型

选择开场对话要用的模型。

这段对话会使用你选的模型。

## 5. 和导师一起定大纲

点**和导师一起定大纲**。导师会读你给的材料，问你已经会什么、有多少时间，再和你一起起草路线。

大纲出现在这段对话里。开始学之前，先在这里改。

## 6. 学完一个路标

学一个路标。先自己作答，再用自己的话说明结果。

这个路标上有了记录，进度环不再是空的。记录可以是一次评估，也可以是你自己写下已经掌握。

![一个路标已记为掌握，进度是 100%](/screenshots/dev/learn-mastery-waypoint.png)
