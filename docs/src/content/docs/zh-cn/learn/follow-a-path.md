一个目标变成一条路线，其中一个路标记下你能做到。你定下一项能力，再学习这条路线上的一个路标。这个路标留着结果。主题要分几次学，你想记下已经能做到的事，就用这一次。做完之后，这个路标上有了记录。路径上的进度环读的就是这条记录。

<aside class="dt-prereq">
<p class="dt-prereq-title">开始之前</p>
<p>先打开应用，并接上一个语言模型。这台电脑还没有的话，从<a href="/zh-cn/get-started/desktop/">桌面端</a>接上。</p>
</aside>

## 1. 打开精通之路

打开**学习 → 精通之路**。

页面列出这个工作区的主题。

## 2. 写下一个目标

创建一个**新的掌握目标**。用一句你做得到的话写下这项能力。例如：“我能说出采样定理，并说明两种采样后的信号在什么情况下无法区分。”

表单里是这句话。标题由它生成。

## 3. 加入一条来源

给这个目标加入一条已保存的记录，作为来源。

这条记录已经加在这个目标里。

## 4. 选择模型

选择开场对话使用的模型。

开场对话会用这个模型。

## 5. 和导师一起设计大纲

选择**和导师一起设计大纲**。导师会读这条来源，询问你已经知道什么、有多少时间，再和你一起画出地图。

大纲出现在这段对话里。开始学习前，在这里改它。

## 6. 学习一个路标

学习一个路标。先自己作答，再用自己的话解释结果。

这个路标上有一条结果，进度环不再是空的。

这个路标记下了一条结果，这一次就完成了。结果可以是一次评估，也可以是你自己声明已经掌握。进度环用的是这条记录。
