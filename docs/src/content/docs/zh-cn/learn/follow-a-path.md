一个主题要分几次才学得完，你又想留下「已经能做到什么」的记录时，用这一课。你先写下一项能演示出来的能力。之后路径上的一个路标会存下结果，进度环读的也是同一条记录。

<aside class="dt-prereq">
<p class="dt-prereq-title">开始之前</p>
<p>先打开应用，并接上一个语言模型。这台电脑还没有的话，从<a href="/zh-cn/get-started/desktop/">桌面端</a>接上。</p>
</aside>

![打开新的掌握目标并写下这项能力](/gifs/learn-follow-a-path.gif)

动图打开**新建精通目标**，把这项能力写进表单，停在**选择资料**之前。

## 1. 打开精通之路

打开**学习 → 精通之路**。

页面会列出这个工作区里的主题。列表是空的，也能看到**新建精通目标**。

## 2. 写下一项能力

选择**新建精通目标**。用一句你做得到的话写下这项能力。例如：“我能说出采样定理，并说明两个采样后的信号在什么时候会分不出来。”

这句话就是目标。路径的标题由它生成。

## 3. 加上一份材料

打开**选择资料**，加入一条已保存的记录。

这条记录会列在目标上。

## 4. 选定模型

选择开场对话要用的模型。

那段对话会使用你选的模型。

## 5. 和导师一起定大纲

选择**和导师一起定大纲**。导师会读你给的材料，问你已经会什么、还有多少时间，再和你一起起草路线。

大纲会出现在那段对话里。开始学之前，先在这里把它改好。

## 6. 学完一个路标

学一个路标。先回答问题，再用自己的话把结果讲一遍。

路标上会留下记录，进度环也不再是空的。记录可以是一次评估，也可以是你自己声明已经掌握。这个路标记下结果，这一课就到这里。

![一个路标已记为掌握，进度是 100%](/screenshots/dev/learn-mastery-waypoint.png)
