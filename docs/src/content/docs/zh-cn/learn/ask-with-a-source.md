手头已经有材料时，从这里开始。讲义、保存下来的一段话，或正在读的论文，都可以。你把它附到一个问题上，回复就会指向你自己能打开的原文。

<aside class="dt-prereq">
<p class="dt-prereq-title">开始之前</p>
<p>先打开应用，并接上一个语言模型。这台电脑还没有的话，从<a href="/zh-cn/get-started/desktop/">桌面端</a>接上。</p>
</aside>

![附上讲义并输入一个需要引用的问题](/gifs/learn-ask-with-source.gif)

动图先打开附件，输入问题，停在发送之前。后面的步骤从发送继续。

## 1. 在项目工作区新建对话

选中这个项目的工作区。打开**主页 → 聊天**，新建一段对话。

输入框是空的。侧栏顶部的名称就是你选中的工作区。

## 2. 附上一份材料

打开资料控件（`+`），附上一份 PDF，或一条已保存的记录。

这份材料列在即将发送的消息上。

## 3. 提一个必须引用原文的问题

发送：“请根据这份讲义说明，为什么采样率太低时，两个不同的信号会看起来一样，并引用讲义里的原文。”

消息进入对话，材料还在这条消息上。

## 4. 先读回复

等回复出现。先读完，再打开材料。

回复至少点出你所附材料里的一处。

## 5. 打开被引用的那一段

打开这处引用，和用到它的那句话对照。

原文会打开，可以和那句话对上。对话里这时既有回复，也有你看过的那一处原文。
