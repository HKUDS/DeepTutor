你拿来一份已经有的 PDF，或一条已经保存的记录。你附上这份来源，再针对它提问。回复会指回它。你可以对照自己的材料核对答案，而不是相信一段查不到出处的笼统回复。讲义、一段保存下来的文字，或一篇正在读的论文，都适合这一次。做完之后，对话里留下这条回复，你也打开了一处来源。

<aside class="dt-prereq">
<p class="dt-prereq-title">开始之前</p>
<p>先打开应用，并接上一个语言模型。这台电脑还没有的话，从<a href="/zh-cn/get-started/desktop/">桌面端</a>接上。</p>
</aside>

## 1. 在项目工作区里新建一段聊天

选中这个项目的工作区。打开**主页 → 聊天**，新建一段聊天。

输入框是空的，工作区名称是你选中的项目。

## 2. 附上一条来源

用资料控件（`+`）加入一份 PDF，或一条已经保存的记录。

这条来源出现在即将发送的消息上。

## 3. 提一个必须给出来源的问题

发送：“结合这份讲义说明，为什么采样率过低会让两个不同的信号看起来相同？请给出来源。”

这条消息已经在对话里，来源还挂在上面。

## 4. 阅读回复

等到回复出现在对话里。先读回复，再打开来源。

回复在对话里，并且至少有一处引用。

## 5. 打开一处引用的来源

从回复里打开一处引用。

来源打开了。把它和引用它的那句话对照。

对话里有回复，并且你打开了一处引用的来源，这一次就完成了。
