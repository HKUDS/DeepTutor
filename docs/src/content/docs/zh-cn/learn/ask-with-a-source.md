手头已经有材料时，从这里开始：一份讲义、保存下来的一段话，或正在读的论文。把它附到同一个问题上，回复就能指向一段你自己打得开的原文。

<aside class="dt-prereq">
<p class="dt-prereq-title">开始之前</p>
<p>先打开应用，并接上一个语言模型。这台电脑还没有的话，从<a href="/zh-cn/get-started/desktop/">桌面端</a>接上。</p>
</aside>

![附上讲义并提出一个需要引用的问题](/gifs/learn-ask-with-source.gif)

动图打开**资料**，输入问题，停在发送之前。后面的步骤从发送接着走。

## 1. 在项目工作区新建对话

选中这个项目的工作区。打开**主页 → 对话**，新建一段对话。

输入框是空的，侧栏顶部的名称就是你选中的工作区。

## 2. 附上一份材料

打开**资料**（`+`），附上一份 PDF，或一条已保存的记录。

这份材料会出现在你即将发送的那条消息上。

## 3. 提一个必须引用原文的问题

发送：“请根据这份讲义说明，为什么采样率太低时，两个不同的信号会看起来一样，并引用讲义里的原文。”

消息进入对话，材料还挂在这条消息上。

## 4. 先读回复

等回复出现，先读完，再打开材料。

回复至少点出你所附材料里的一处原文。

## 5. 打开被引用的那一段

打开这处引用，和用到它的那句话对照。

那段原文会打开。回复已经在对话里，你也亲自核对过一处来源，这一课就到这里。
