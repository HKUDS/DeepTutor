讲解已经读完，想看看不看它还能答出什么时，用这一课。你要一套短练习，收进这个工作区的题库，再凭记忆答一题，最后才看参考答案。

<aside class="dt-prereq">
<p class="dt-prereq-title">开始之前</p>
<p>先打开应用，并接上一个语言模型。这台电脑还没有的话，从<a href="/zh-cn/get-started/desktop/">桌面端</a>接上。</p>
</aside>

![选择测验并输入出题要求](/gifs/learn-practice-a-topic.gif)

动图打开**模式**，选择**测验**，再输入要求。输入框旁会打开**测验设置**。题目要等你发送之后才出现。

## 1. 选择测验

在[对话](/zh-cn/learning-workspace/chat/)里打开**模式**，选择**测验**。测验会为这一轮写出一套练习。

消息上会出现**测验**，输入框旁会打开**测验设置**。

## 2. 要一套题

指定一个主题；也可以先附上材料，再按这份材料出题。然后发送。

一套题目会出现在对话里。

## 3. 收进题库

题目看起来能用时，把它们收进这个工作区的题库。

这套题就存进去了。

## 4. 先凭记忆答一题

打开**资料 → 题库**，选中这套题，开始练习。揭开答案之前，先自己回忆一遍。

眼前是一道题，答案还藏着。

## 5. 再看参考答案

打开参考答案，评级按钮就在同一张卡片上。

答完这一题、也看过参考答案，这一课就到这里。这套题还留在题库里，以后可以从那里再打开。

![参考答案已经展开，评级按钮也在](/screenshots/dev/learn-practice-answer.png)
