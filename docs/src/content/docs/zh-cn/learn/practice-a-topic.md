讲解已经读过，想看看不看着它还能答出什么时，用这一课。你要一套短练习，收进这个工作区的题库，先凭记忆答一题，再看参考答案。

<aside class="dt-prereq">
<p class="dt-prereq-title">开始之前</p>
<p>先打开应用，并接上一个语言模型。这台电脑还没有的话，从<a href="/zh-cn/get-started/desktop/">桌面端</a>接上。</p>
</aside>

![选择测验并输入出题要求](/gifs/learn-practice-a-topic.gif)

动图在模式里选测验，再输入出题要求。旁边会打开测验设置。题目要等你发送之后才会出现。

## 1. 选择测验

在[对话](/zh-cn/learning-workspace/chat/)里打开**模式**，选择**测验**。测验会按这一轮写出一套练习。

消息上出现**测验**，旁边打开**测验设置**。

## 2. 要一套题

指定一个主题，或先附上材料，再按那份材料出题。然后发送。

一套题目出现在对话里。

## 3. 收进题库

题目能用时，收进这个工作区的题库。

题库里能再找到这套题。

## 4. 先凭记忆答一题

打开**资料 → 题库**，选中这套题，开始练习。揭开答案之前，先自己回忆。

你看到的是一道题，答案还藏着。

## 5. 再看参考答案

打开参考答案。评级就在同一张卡片上。

这一题答过了，参考答案也看到了。这套题留在题库里，以后还可以从那里再打开。
