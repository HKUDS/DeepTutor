---
title: 练一个主题
description: 生成一套练习，收进题库，并答完其中一题。
quadrant: tutorial
---

学完一个主题之后，你确认自己还能不能回忆起来。你要一套短练习，并把这套题收进题库。你先凭记忆答其中一题，再读参考答案。讲解已经读过，你想看看不看着它还能答出什么，就用这一次。做完之后，你答过一题，这套题也留在这个工作区里。之后还能从题库再打开这套题。

<aside class="dt-prereq">
<p class="dt-prereq-title">开始之前</p>
<p>先打开应用，并接上一个语言模型。这台电脑还没有的话，从<a href="/zh-cn/get-started/desktop/">桌面端</a>接上。</p>
</aside>

## 1. 选择测验

在[对话](/zh-cn/learning-workspace/chat/)里选择 **测验**。测验会根据这段对话写出一套练习。

这一轮选中的是 **测验**。

## 2. 生成一套题

针对一个主题出题，或先附上材料，再按那份材料出题。

一套题目出现在对话里。

## 3. 收进题库

题目看起来能用时，收进这个工作区的题库。

这套题已经在这个工作区的题库里。

## 4. 答一题

打开**资料 → 题库**，选中这套题，开始练习。先回忆，再看答案。

你正在看一题，答案还没有展开。

## 5. 看参考答案

读参考答案。评级控件在同一张卡片上。

你答完其中一题，并看到了参考答案，这一次就完成了。
