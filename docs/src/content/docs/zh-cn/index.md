DeepTutor 将对话、来源材料、学习活动与可复用的辅助能力组织在同一个应用中。先为一门课程、一个项目或一个学习目标建立 **工作区**：其中的 **主页、学习、资料** 保存这个工作区的内容；**伙伴、个性化** 属于你的账户，切换工作区后仍可使用。

## 让功能围绕同一件事协作

第一个项目可以很小：一个主题、一份来源，以及一个想弄明白的问题。[产品使用路线](/zh-cn/explore/)会带你经过五个入口，说明何时附加上下文、何时保存原文，以及何时将材料转为结构化学习活动。

例如，创建“信号处理”工作区，在知识库中加入一份简短讲义；回到主页，让助手结合来源解释采样；将有用段落保存到收藏夹，再在学习笔记本里整理自己的理解。接着用精通之路或练习检验掌握程度。研究型角色或伙伴可以在另一个工作区继续帮助你，而不需要把两个项目的材料混在一起。

## 按实际需要配置

[模型提供方](/zh-cn/get-started/providers/)介绍语言模型和 embedding 的配置；[设置](/zh-cn/explore/settings/)说明界面偏好、服务、模块和就绪状态。功能是否出现取决于模块的安装与启用情况；最小 core 安装的入口会少于文档展示的完整应用。

多人部署前，请阅读[多用户配置](/zh-cn/get-started/multi-user/)。“账户级”表示在**同一账户的多个工作区之间**复用，不表示自动向服务器上的所有用户共享。
