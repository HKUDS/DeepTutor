打开 **设置 → 模型与服务（Settings → Models & services）** 时，你会看到提供方、语言模型、后台任务模型、嵌入模型、搜索、语音与多模态七个入口。你不需要把它们全部配完才能使用 DeepTutor。

这篇指南帮你弄清三件事：**这些词分别是什么意思**、**第一天真正需要配哪一个**，以及**新手最常踩哪些坑**。如果你已经熟悉概念、想直接查各平台的默认地址和本地模型参数，请看[提供方与参数参考](/zh-cn/get-started/providers/)。

## 1. 一分钟看懂四个核心词

| 概念 | 界面名称 | 大白话解释 |
| --- | --- | --- |
| **提供方** | Providers（提供方） | **“你从哪家平台拿 AI”**，例如 DeepSeek、OpenAI、通义千问（DashScope）、OpenRouter 或本地的 Ollama。在 **提供方** 页面保存一次凭据，这家平台支持的所有服务都能共用这份密钥。 |
| **模型** | Models（模型） | **“具体干活的 AI 型号”**。同一家提供方通常会提供多个型号——有的擅长快速对话，有的擅长复杂推理，有的能看懂图片。 |
| **API Key** | API key | **“给程序用的门禁卡”**。它是平台颁发的一串随机字符（常见以 `sk-` 开头），用于验证身份并按用量计费。它**不是**你的网页登录密码。 |
| **接口地址** | Provider URL / Base URL | **“程序发请求的门牌号”**。使用官方平台时，按页面提示留空就会走默认地址；使用中转网关或自建服务时，需要填平台文档给出的 API 地址（不是厂商官网首页）。 |

## 2. 七类服务：第一天配哪一个，其余何时再配？

在 **设置 → 运行状态（Runtime status）** 中，DeepTutor 会把每项能力评为阻塞、警告或建议；没有配置的可选服务不会被当作故障。

### 唯一必填（第一天配这一个就够了）

- **语言模型（Language models）**：驱动对话、解题、出题、深度研究、精通之路、书籍与学习笔记的核心大脑。**配好它，DeepTutor 的绝大部分功能就能立刻使用。**

### 开箱即用（不配也能用）

- **搜索（Search）**：联网搜索工具 `web_search` 默认启用，未配置搜索提供方时会自动使用免密钥的 **DuckDuckGo**。只有当你需要更高搜索质量、国内直连（如豆包、博查、智谱、百度千帆、阿里云 IQS）或想显式关闭联网搜索（选择 `none`）时，才需要进入 **搜索** 页面修改。

### 按需选配（以后用到对应功能再配）

| 服务 | 它解锁什么功能？ | 什么时候再配？ |
| --- | --- | --- |
| **嵌入模型（Embedding models）** | 把你的 PDF / 讲义切分并转成可检索的向量，让 AI 在大堆资料里精准找到原文。 | **准备创建知识库（Knowledge Base）时**。单次对话里用 `+` 临时附一份文件，不需要配嵌入模型。 |
| **后台任务模型（Task models）** | 处理自动生成对话标题、起始建议、阅读辅助，以及数学动画/视频课的代码修复。 | 想把后台杂活交给更便宜、更快的轻量模型时。不配也能正常使用。 |
| **语音（Voice：TTS / STT）** | **语音合成（TTS）** 朗读回复与阅读材料；**语音识别（STT）** 解锁输入框旁的麦克风。 | 想听语音讲解或用语音提问时。 |
| **多模态生成（Multimodal）** | 解锁聊天里的 `imagegen`（画图）和 `videogen`（生成视频）工具。 | 想让 AI 在对话里直接为你生成插图或短视频时。 |

:::caution[拍照解题 / 论文读图不需要配“多模态生成”]
“看图”依靠的是**语言模型自身的图像输入（Vision）能力**，不是 **多模态** 页面里的文生图服务。如果你需要拍照解题或看懂论文里的图表，在 **语言模型** 中选择支持图像输入的型号即可。
:::

## 3. 三种获取模型的方式，怎么选？

| 方式 | 适合谁 | 费用与门槛 | 典型代表 |
| --- | --- | --- | --- |
| **已有账号直接登录（OAuth）** | 已经订阅了对应会员、不想折腾 API Key 的用户 | 复用已有账号权限与额度，在浏览器完成授权 | **OpenAI Codex**（ChatGPT 账号）、**GitHub Copilot**、**CodeBuddy / WorkBuddy** |
| **云端 API Key（按量付费）** | 大多数学习者；无需本地显卡，可自由切换国内外强模型 | 到对应平台的 API 开放平台创建密钥并确认余额，按实际用量扣费 | 国内直连：**DeepSeek**、**通义千问（DashScope）**、**智谱（GLM）**、**硅基流动（SiliconFlow）**、**火山引擎（VolcEngine）**<br/>海外/聚合：**OpenAI**、**Anthropic**、**Gemini**、**OpenRouter** |
| **本地运行模型** | 注重隐私、想离线免费使用、且电脑内存或显卡充足的用户 | 免费，无需 API Key；速度与效果取决于本机硬件 | **Ollama**、**LM Studio**、**llama.cpp**、**Lemonade**、**vLLM** |

:::caution[网页聊天会员 ≠ API 额度]
你在 OpenAI、DeepSeek、Claude 等官网购买的网页版会员（例如 ChatGPT Plus），通常**不包含** API 开放平台的调用额度。使用 API Key 方式时，需要到厂商的 **API 开放平台 / 开发者控制台** 创建密钥并检查余额。如果你想直接复用 ChatGPT 订阅权限，请在提供方中选择 **OpenAI Codex**（账号登录），而不是 **OpenAI**（API Key）。
:::

## 4. 看懂模型卡片上的四项能力开关

在 **设置 → 模型与服务 → 语言模型** 中，DeepTutor 会根据型号自动识别模型能力，你也可以按需要手动调整四项开关：

<!-- TODO(screenshot): 补充“设置 -> 语言模型”中单个模型卡片的截图，标出 Tool calling、Image input、JSON output、Reasoning 四项能力开关（建议保存到 docs/public/screenshots/dev/models-capabilities.png）。 -->

| 能力标记 | 影响什么体验 | 选型建议 |
| --- | --- | --- |
| **工具调用（Tool calling）** | 决定 AI 能不能查资料、搜网页、记笔记、调用工作区工具 | 优先选择支持工具调用的主流模型，这是发挥 DeepTutor 完整工作流的基础。 |
| **图像输入（Vision / Image input）** | 决定 AI 能不能看懂题目照片、截图与 PDF 插图 | 需要拍照解题、读图表论文时必选。 |
| **推理支持（Reasoning）** | 决定模型是否支持深度思考，以及能否调节 **推理强度（Reasoning effort）** | 做高难数理推导、深度研究时效果更好；日常问答可以把推理强度调低以加快速度。 |
| **JSON 输出（JSON output）** | 影响出题、生成精通之路与书籍大纲时的结构稳定性 | 主流云端模型基本都支持；使用小参数本地模型如遇格式报错，可检查此项。 |

## 5. 草稿—应用机制：怎么改都不怕把旧配置弄坏

DeepTutor 的设置页采用 **草稿—应用（draft-and-apply）** 模式：修改先存在草稿里，测试确认可用后再正式生效。

1. **连提供方**：打开 **设置 → 模型与服务 → 提供方**，添加提供方并点击 **Test provider**。
2. **加模型并测试**：打开 **语言模型**，导入或添加具体型号，点击 **Test model** 验证通过后点击 **Set as default**。
3. **应用更改**：点击页面底部栏的 **Apply changes（应用更改）**，等待状态变为 **Applied**。

模型配置保存在 `data/user/settings/model_catalog.json` 中；项目根目录的 `.env` 文件不会被自动加载。

:::caution[建好知识库之后再换嵌入模型要注意什么？]
如果你已经创建过知识库，之后在 **嵌入模型** 页面更换了不同型号或向量维度，旧索引会与新模型不匹配。DeepTutor 会自动检测并提醒你——按提示对受影响的知识库执行 **重建索引（Re-index）** 即可，原始文档不会丢失。
:::

## 6. 新手常见报错与排查

| 你遇到的情况 | 最常见原因 | 怎么解决 |
| --- | --- | --- |
| 提示 `No active LLM model is configured` | 没有设为默认模型，或者只点了 **Save draft** 没点 **Apply changes** | 回到 **语言模型**，确认模型标有 **Default model**，再点击底部 **Apply changes**。 |
| **Test provider** 通过，但 **Test model** 失败 | 平台连通了，但账号没有该具体型号的权限、余额不足，或 Model ID 拼写有误 | 换一个账号有权限的型号，核对平台文档中的准确 **Model ID**，并检查 API 余额。 |
| 填写 URL 后一直超时或连接失败 | 把厂商官网首页当成了 API 地址，或照抄了示例占位符 `https://api.example.com/v1` | 官方平台留空走默认地址；中转或自建服务请核对平台接入文档给出的完整 API 地址，并检查网络。 |
| Docker 部署后连不上本机 Ollama | 在容器里，`localhost` 指的是容器自己，不是宿主机 | 把地址中的 `localhost` 换成 `host.docker.internal`，详见[Docker 文档](/zh-cn/get-started/docker/)。 |
| 改完默认模型，旧对话里还是老模型 | 已有对话会保留之前的会话级模型选择 | 在该对话输入框旁的模型选择器里手动切换，或新建一段对话。 |

## 7. 进阶提示：接通首个模型后，可以直接在对话里改设置

只要第一个语言模型已经能正常对话，后续很多配置都可以直接在聊天框里用自然语言完成（例如切换界面语言、检查服务就绪状态）。DeepTutor 会先在未落盘的候选配置上探测改动是否可行；涉及填写 API Key 时，输入框会弹出专用表单直接提交给本地服务端，**密钥不会进入对话上下文**。
