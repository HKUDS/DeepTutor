生成一套题并答完其中一题，按[练一个主题](/zh-cn/learn/practice-a-topic/)走一遍。

先生成一套题，收进这个工作区的题库，再从题库里做一次。导入自己的题目、复习日程和错题列表在这一页后面。

## 生成一套题，再复习一次

1. 在[对话](/zh-cn/learning-workspace/chat/)里选择 **测验**。测验会根据这段对话写出一套练习。
2. 针对一个主题出题，或先附上材料。
3. 题目看起来能用时，收进这个工作区的题库。
4. 打开**资料 → 题库**，选中这套题，开始练习。
5. 先回忆，再看答案。

你答完其中一题，并看到了参考答案，这一次就完成了。

## 练习在哪里

练习把学习活动里的题目变成可以重复做的复习。今天要复习的，从**学习 → 练习**（`/learning/practice`）进入。整理题目、查看错题或手选一套，从**资料 → 题库**进入。两边用的都是当前工作区的题目。

## 建立题目集合

支持的聊天、书籍和精通之路活动产生的题目，可以汇入题库。你也可以导入自己的材料。

1. 在练习或题库中选择**导入题目**。
2. 选择导入**题库**或**错题**。
3. 下载 XLSX 或 CSV 模板，也可以自己准备 XLSX、CSV、TSV 或 JSON。每一行都要有题目和正确答案。标签用来整理。中英文列名都可以。
4. 上传并检查预览。每个文件最多 **500 题、5 MB**。XLSX 读取当前活动工作表。
5. 修正报错的行，重新上传，再点击**确认导入**。预览本身不会保存。已经在题库里的相同题目会跳过，标签合并到原题目上。

例如，把 30 个定义打上 `概率论` 和 `第二章` 的标签导入，考前在题库里选一个短题组。

## 完成一次复习

有到期题目时，打开练习，选择**开始今日复习**。先回忆，再看答案。支持答案检查时，可以提交你的作答。看完参考答案和解析，再按实际回忆情况评级。

| 评级 | 适用情况 |
| --- | --- |
| **重来（Again）** | 需要在本轮再次尝试 |
| **困难（Hard）** | 需要提示，或回忆吃力 |
| **已掌握（Mastered）** | 能回忆出来，过几天再复习 |
| **简单（Easy）** | 确信自己熟悉答案 |

**重来**会在本轮再次出现。保存评级会更新下次到期日。跳过的题目仍然待复习。结束时会显示已保存的复习次数和下一次日期。今日队列优先安排逾期题，每组最多 20 题。新的错题会在次日回来。

## 整理与诊断

在题库里可以查看题目、你记录的作答、正确答案和解析。用分类、来源和错题筛选缩小范围，再从选中的题目开始练习。练习分析让你看到复习的规律。你记下的评级就是这次复习。它和一次评估后的能力证明是分开的。

没有到期题时，页面会说明当前复习已经完成。你仍然可以从题库里手选题目来练。集合内容不对时，先看当前工作区，再决定要不要重新导入。

## 和导师一起看

同一题反复出错时，回到来源对话，或在[阅读](/zh-cn/learning-workspace/reading/)里打开相应材料。让助手解释这一题，再在[学习笔记本](/zh-cn/learning-workspace/notebook/)里写一个你自己的例子。要评估一项更完整的能力，用[精通之路](/zh-cn/learning-workspace/mastery/)。练习安排的是下一题什么时候再回忆。路径记录的是你是否已经表现出这项能力。
