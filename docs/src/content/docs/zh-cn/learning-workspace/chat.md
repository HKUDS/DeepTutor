附上一条来源并打开一处引用，按[带着材料学习](/zh-cn/learn/ask-with-a-source/)走一遍。

先发一条自己带上来源的消息，再读回复。窗口怎么分、哪些选择会留下来、对话背后的文件夹，都在这一页后面。一轮对话怎么规划、调用工具、再停下来，见[智能体循环是怎么工作的](/zh-cn/learning-workspace/agent-loop/)。

## 发出一条带上来源的消息

1. 选中这个项目的工作区，新建一段聊天。
2. 用资料控件加入一份 PDF，或一条已经保存的记录。问题需要在整个资料库里查找时，再挂上知识库。
3. 写明你要的结果，以及先不要做什么。例如：“基于这份讲义解释采样定理，再给我两道题。先让我尝试，不要直接展示答案。”
4. 在活动面板里看工具的进度。要核对依据时，打开它引用的来源或生成的文件。
5. 把有用的结果存进[收藏夹](/zh-cn/learning-workspace/favorites/)，或在[学习笔记本](/zh-cn/learning-workspace/notebook/)里写下你自己的理解。以后从资料 → 聊天历史重新打开这段对话。

回复出现在对话里，并且你核对过它用到的一处来源，这一次就完成了。

你选中的连接智能体会留在这段对话上。导入的旧记录只是这一条消息的材料。附上的文件默认只给这一轮用。工作区指令和对话上的选择会影响后面的轮次。如果回复用错了来源或人设，再次发送前先看输入框上的标签。

## 它在哪里

先选择[工作区](/zh-cn/learning-workspace/workspaces/)，再打开**主页 → 聊天**（`/chat`）。主页里还有[任务看板](/zh-cn/learning-workspace/task-board/)、[学习笔记本](/zh-cn/learning-workspace/notebook/)和[日历](/zh-cn/learning-workspace/calendar/)。聊天、任务和笔记本跟着工作区走。日历上的事件属于账户，也可以带上某个工作区的学习信息。

![主页与对话输入框](/screenshots/dev/overview.png)

界面分为三个区域：

| 区域 | 作用 |
| --- | --- |
| **左侧栏** | 顶部是工作区菜单，下面是**主页、学习、资料**。**伙伴**和**个性化**属于账户。对话重新打开时，会带回当时的学习上下文。设置和工作区管理在工作区菜单里。经典布局的导航排列不一样。 |
| **输入框** | 消息框。**左下角**选择这一轮的能力（capability，也就是这次要走的流程），并用 `+` 加入引用。**右下角**是连接智能体、知识库、人设和模型。麦克风只把当前这条消息转成文字。 |
| **活动面板**（右上角切换） | 当前这段对话用过的工具调用、引用、生成的文件、附件和预览，也可以快速打开一个 URL 或本地文件。 |

打开身份认证后，已登录的人还会在侧栏看到 **My profile**。这里显示用户名（这里不能改）、角色和加入日期。你可以上传头像，或选一个图标和颜色，也可以退出登录。

对话上方右侧的图标用来：**把有用内容存到收藏夹**、**把整段会话导出为 Markdown**、**展开或收起活动面板**。

## 输入框还空着的时候

空白输入框下面有解释、解题、练习、规划和研究这几条可改的提示。另外一条建议来自你的记忆和最近的活动。**换一批**会换掉这条建议。点一条，内容先进入输入框。你看过再发送。常用的标题和请求在**自定义页面 → 起始提示**里改。

**Settings → Conversation** 决定这些建议能看到多少历史。活动条数调高，建议会参考更多最近做过的事。调低，建议就贴近刚才那几件事。

## 会留下来的选择，和只用于这一条的材料

输入框把上下文分成两类，放在两处。

**会留下来的选择**一直生效，直到你改掉：能力、工作区或课程绑定、工具、**知识库**、**人设**、**模型**，以及阅读 / 精通之路的状态。选择器在右侧。用 Agent 胶囊或 `@` 选中的智能体会留在这段对话里。麦克风只填写当前草稿。

**引用**在左侧的 **`+` 按钮**后面，默认只用于这一轮。某种引用后面每一轮都要用时，打开复用控件。

| `+` 引用 | 拉进什么 |
| --- | --- |
| **Attach files** | 一份 PDF、图片、Office 文档、Markdown 或数据文件，交给智能体阅读。 |
| **Chat History** | 把过去的某段会话作为背景资料。 |
| **My Agents** | 一份导入的 Claude Code / Codex / ChatGPT 对话记录，用来查看。见[我的智能体](/zh-cn/customize/agents/)。 |
| **Books / Reading / Notebooks / Question Bank** | 一本已编译的书、一段阅读、一个已保存的笔记本，或[资料](/zh-cn/learning-workspace/resources/)里的练习题。题目可以按材料或分类筛选。**Select all** 会保留先前的选择。 |
| **Memory** | 某一份具体的记忆文档。你要它依据一份你点名的记忆，而不是它自己召回的内容。 |

在主对话输入框里键入 **`@`**，会筛出和 Agent 胶囊相同的连接智能体列表，并把选中项留在这段对话里。没有这个智能体选择器的后续界面，用 `@` 打开 Space 引用菜单。

### 知识库

**数据库图标**打开知识库选择器。你还没动手选过的对话，会沿用工作区里已经就绪的指定库，或默认库。你做出的选择，包括一个都不选，会一直保留到你修改。回答需要依据时，智能体从这些库里检索。

检索方式取决于这个库绑定的引擎。大多数库由 `rag` 工具负责：LlamaIndex、GraphRAG、LightRAG、链接好的现成索引、远端 LightRAG Server、腾讯 IMA 库。**PageIndex OSS** 和 **PageIndex Cloud** 不是：它们会顺着本地或托管的文档树往下读，所以故意不出现在 `rag` 的列表里。**Obsidian** 库没有索引，会交给 Obsidian 能力，由它直接浏览当前文件。**MarginNote 4** 库也是这样，用它自己的一组工具。

### 人设

**人物图标**用来选人设。人设决定语气和教学立场。`Default` 是朴素的助手。内置的 **peer**（同伴）、**research-assistant**（研究助理）、**teacher**（老师）会改变语气。人设在**个性化 → 人设**里管理，伙伴也可以复用。

### 模型

**模型胶囊**决定这一轮用哪个模型。你在设置里配好的每个模型都会列在这里，并标上提供方和上下文窗口，默认模型有标记。提供方是托管这个模型的厂商，或你本机的服务。大文档换成长上下文的模型，短对话换成更省、更快的模型。对话中途可以换，已经写过的内容还在。

## 活动面板

右上角的开关打开 **Activity**。它是这段对话用过的工具、引用和文件的实时记录。生成的文件排在你上传的文件上面。**Open** 框可以把一个 URL 或本地文件拉进应用里的查看器。

![对话与活动控制](/screenshots/dev/chat.png)

一轮进行时，每次工具调用会收成一个短标题（例如 `Done · 21s`）。展开就能看到输入和输出。对话保持可读，完整记录也还在。

## 内容工作区

**内容工作区**是绑在对话上的文件夹。还没绑定的会话使用通用工作区。你可以为不同项目各自建一个工作区。系统工作区保存共享的技能，以及去掉敏感内容的配置快照。技能是一段可以反复套用的做法。私有的运行设置、API key、数据库和记忆不在对话能打开的文件里。

在 **Settings → Workspace** 里管理根目录、工作区和 **Workspace instructions**。指令从下一轮开始，对支持的能力生效。Deep Research、Quiz 和 Manim 不接收这些指令。能力自己的规则和权限仍然有效。内置目录和托管的自建目录默认在 `<runtime-home>/data/user/workspaces`。命令行仍可管理原来的内容文件夹绑定：

```bash
deeptutor workspace show
deeptutor workspace set /absolute/path/to/my-folder
deeptutor workspace reset
```

这一轮可以读这个文件夹。它产生的东西，包括下载、生成的文件、代码输出和渲染出的素材，都落在按回合分开的 `outputs/<capability>/<session>/<turn>/` 目录里。文件夹的其余部分对这次执行是只读的。要把生成的文件从 `outputs/` 复制到你自己的材料里，需要一次 **Allow once** 确认，确认框会写明从哪里复制到哪里。

模型看到的是 `outputs/report.docx` 这样的相对路径，看不到绝对路径。它调用 `workspace_present` 时，界面会给出一份带登录校验、可以打开的快照。同一个相对路径也可以写进普通的 Markdown 链接或图片。之后再改源文件，已经呈现过的快照保持原样。

在 Docker 和服务器部署里，托管工作区的存储范围由部署文件夹限制。见 [Docker](/zh-cn/get-started/docker/)。

## 在手机上

宽度小于平板时，工作区变成一栏，侧栏可以滑出，同一段对话在手机上能用。

## 实用示例

```text
挂载一个知识库 + 提问：「讲讲第 4 章，并就我薄弱的点考我。」
```

```text
附加一份 PDF + 提问：「抽取其中的假设，并把最终摘要存进我的笔记本。」
```

```bash
deeptutor run chat "讲讲傅里叶变换" --kb signals
deeptutor chat --capability deep_research --kb papers
```
