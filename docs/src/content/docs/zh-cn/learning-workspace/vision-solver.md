视觉解题是 **Solve** 能力在读一张图片。同一轮可以规划步骤、做检查；几何图形还可以调用 GeoGebra。

## 解出一张照片

1. 在这个学科的工作区打开[对话](/zh-cn/learning-workspace/chat/)。
2. 在能力菜单里打开 **More Capabilities**，选择 **Solve**。
3. 用 **+** 附上题目照片。裁到你要解的那一题。
4. 发送：“解这道题。先写出每一步，再给最终答案。图看不清就停下来问我。”
5. 在线程里核对步骤。需要工具轨迹时打开活动面板。

线程里出现一份你能对照照片核对的解答，这条路径就完成了。

## 几何图形

如果照片是几何作图，发送前在 **设置 → 工具** 里打开 `geogebra_analysis`。Solve 可以把图形转成 GeoGebra 命令。纯代数题保持关闭。

## 把题目留下来

解答值得再练时，收进[出题与练习](/zh-cn/learning-workspace/questions/)。要检验一个更大的主题，用[精通之路](/zh-cn/learning-workspace/mastery/)，而不是这一张照片。
