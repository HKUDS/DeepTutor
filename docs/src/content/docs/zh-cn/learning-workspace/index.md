把一个项目从它的工作区走到对话、学习和资料。下次打开时，从已经保存的内容接着做。伙伴和个性化留在账户上。

## 两种范围，五个入口

| 入口 | 范围 | 用途 |
| --- | --- | --- |
| [对话](/zh-cn/learning-workspace/chat/) | 工作区 | 对话、任务看板、学习笔记本 |
| [书籍](/zh-cn/learning-workspace/books/) | 工作区 | 书籍、精通之路、阅读集合、练习 |
| [资料](/zh-cn/learning-workspace/resources/) | 工作区 | 聊天记录、收藏夹、题库、学习日志、知识库 |
| [伙伴](/zh-cn/channels/) | 账户 | 持久伙伴的指令、资源访问与渠道 |
| [个性化](/zh-cn/customize/) | 账户 | 角色、技能、外部智能体、MCP、CLI 应用与记忆控制 |

技能是一段可以反复套用的做法。MCP 是一条连接，让 DeepTutor 调用应用外面的工具。

**日历是主页里的一个例外：** 它按账户显示，能看到各个工作区的安排。[日历指南](/zh-cn/learning-workspace/calendar/)说明怎么辨认一条日程来自哪个工作区。伙伴也有自己的工作范围。它挂在账户上，不代表每一段对话都能读到所有工作区。

## 1. 给项目一个独立工作区

为“信号与采样”新建或选中一个工作区，把讲义和练习与“学术写作”分开。加材料、开始学习之前，先看当前工作区的名字。切换之后，对话、书籍和资料显示的是这个项目。伙伴列表和个性化库仍然在。详见[工作区与切换](/zh-cn/learning-workspace/workspaces/)。

## 2. 先带上来源，再问一个具体问题

以后还要用的材料，放进[知识库](/zh-cn/learning-workspace/knowledge/)。想让原文开在旁边，就在[阅读](/zh-cn/learning-workspace/reading/)里打开那份文档。回到主页，附上你指的那份材料，再问清楚，例如：“结合这份讲义说明，为什么采样率过低会让两个不同的信号看起来相同？请给出来源。”

以前保存的文件不会自己进入下一问。你要附上它，或者选中这个活动提供的学习上下文。顺着答案往下想之前，先读它引用的段落。

## 3. 把证据和你自己的理解分开

可能还要再用的原文，存进[收藏夹](/zh-cn/learning-workspace/favorites/)。你怎么理解，写在[学习笔记本](/zh-cn/learning-workspace/notebook/)里，需要时插入引用。笔记本是你的解释，收藏夹留着原文。某个结论看着不对，就回到原文。某一段要改，就在那段旁边问 Dito。

## 4. 选一种适合的学法

- [书籍](/zh-cn/learning-workspace/books/)：一页一页往下走，页面里有可以操作的块。
- [精通之路](/zh-cn/learning-workspace/mastery/)：目标拆成几个主题，按路径学。
- [阅读](/zh-cn/learning-workspace/reading/)：问题对着一份文档，或媒体里的一个时间点。
- [练习](/zh-cn/learning-workspace/questions/)：做题，看反馈，再回到没掌握的地方。

这是处理同一个主题的不同方式，不必按这个顺序做完。先选一种。用那个画面上的保存或附加，把结果带到下一次活动。

## 5. 接着用原来的助手，别把项目混在一起

选一个会让你讲清推理过程的角色。想重复同一种做法时，加上对应的技能。想再听一个看法，就接一个外部智能体，或者给伙伴定好角色，并限制它能看到哪些资源。这些都在账户上，下一个工作区还能用。每个工作区保留自己的材料和学习记录。

## 下次从哪里继续

在主页用[任务看板](/zh-cn/learning-workspace/task-board/)记下下一步。到[资料](/zh-cn/learning-workspace/resources/)里找存过的证据和以前的对话。从学习列表重新打开一个活动。换科目不用重新配置应用，也不用把伙伴再创建一遍。
