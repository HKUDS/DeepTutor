给一个路标记下结果，按[沿着路径学完](/zh-cn/learn/follow-a-path/)走一遍。

精通之路把一个目标变成一条走得完的路线，并记下你是否已经表现出这项能力。先跟一个主题。模式、证据类型和复习日程在这一页后面。

## 跟一个主题，直到记下结果

1. 打开**学习 → 精通之路**，创建一个**新的掌握目标**。
2. 写下你希望能做到的事。例如：“在大一考试题中选择并使用换元或分部积分，并解释方法为何成立。”标题由这个目标生成，之后可以改名。
3. 放入学习要依据的材料：一本书、一条已保存的笔记本或收藏记录，或知识库里的文件。
4. 先选择开场对话使用的模型，再选择**和导师一起设计大纲**。导师会读材料，询问你已经知道什么、有多少时间，再和你一起画出地图。开始学习前，在这段对话里改大纲。大纲不再是创建表单里的第三步。
5. 学习一个路标。先自己作答，再用自己的话解释结果。

这个路标记下了一条结果，这一次就完成了。结果可以是一次评估，也可以是你自己声明已经掌握。这两条分开保存。进度环用的是这条记录，不是页面开了多久。

## 它在哪里

从左侧栏的**学习 → 精通之路**进入，或访问 `/learning/mastery`。地图显示这个工作区的主题、下一个路标和总体进度。资料里是可以反复使用的材料。个性化属于账户。

## 一次学习一个路标

学习界面把当前主题、路标、进度环、大纲、对话记录和输入框放在一起。记录上方有三种**模式**：大纲、学习、复习。当前模式决定导师能用哪些工具。只有大纲能改地图；调整模块顺序时，先看预览再确认。只有学习和复习能考你。Activity 抽屉和侧边查看器留着工具、引用和生成的材料。

题目可以单独出现，也可以两到四题一组。卡片结束这一回合。每一题单独评估，分成几次提交也可以。概念卡片和设计卡片是练习。要算掌握，仍然需要你自己的解释。**掌握门槛**依据评估决定能否往下走。你也可以自己声明某个知识点已经掌握，这条记录和评估通过分开保存。完成的知识点到期后，会通过**间隔复习**再出现。

![精通之路主题与学习界面](/screenshots/dev/mastery-detail.png)

一轮对话结束后，配置好的 **Task Model** 可以根据当前路标和最近的对话，写出下一条建议问题。输入框为空时，按 **Tab** 接受建议。它先留在输入框里，你发送之后才会进入对话。

## 对话留在主题下面

学习会话是绑在精通之路上的普通对话。侧栏把它留在这个主题下面。重新打开会恢复地图和路标。在普通对话里，DeepTutor 可以给出一张交接卡，用来继续或新开一段学习。你点击之后才会跳过去。

## 结果是怎么记下的

每个知识点会标成 *memory*、*procedure*、*concept* 或 *design*。类型决定什么样的证据才算掌握，也帮助导师选择学习活动。只看懂答案，不足以证明概念或设计能力。

路径和学习对话属于当前工作区。重新打开主题，可以恢复地图和会话。从到期复习的入口回顾以前的依据。看进度环时记住这个区别。你自己的声明，和一次评估的结果，是两条记录。练习补的是单题的回忆。学习笔记本留着你写下的解释。
