精通之路把宽泛目标拆成一条真正能走完的路线。路线由模块和不同类型的知识点组成，进度记录评估通过或明确的学习者掌握声明，而不是读了多久。

## 它在哪里

从左侧栏的**学习 → 精通之路**进入（或访问 `/learning/mastery`）。主题地图会显示每个主题、下一个路标与总体进度。资料保存工作区的可复用材料，个性化设置属于账号层。

![精通之路列表](/screenshots/dev/mastery.png)

## 创建一条路径

创建一个**新的掌握目标**，只需两步：

1. **目标**——描述希望建立的能力。标题由目标生成，之后可重命名。
2. **材料**——选择书籍、已保存的 Notebook／收藏记录或知识库文件作为学习依据。

先选择开场对话使用的模型，再选择**和导师一起设计大纲**，进入大纲对话：导师阅读材料、询问已有知识与可用时间，再与你一起设计地图。开始学习前可讨论修改；大纲不再是创建向导的第三步。

每个知识点会标为 *memory*、*procedure*、*concept* 或 *design*。类型决定什么证据才算掌握，也帮助导师选择合适的学习活动。

## 一次攻克一个路标

学习界面把当前主题、路标、进度环、大纲、对话记录与输入框放在一起。记录上方有三种**模式**——大纲、学习、复习——决定导师能用哪些工具：只有大纲能改动地图，模块重排须先预览再确认；只有学习与复习能考你。Activity 抽屉和侧边查看器保留工具、引用与生成材料。题目可单独或两至四题成组，卡片结束该回合；逐题评估，可分次作答。概念与设计卡片只作练习，掌握仍须评估自己的解释。**掌握门槛**依据评估控制推进；学习者也可明确声明已掌握，来源会与评估通过分开记录；已完成的知识点会在到期时通过**间隔复习**再次出现。

![精通之路主题与学习界面](/screenshots/dev/mastery-detail.png)

一轮对话结束后，配置好的 **Task Model** 可以结合当前路标和近期对话写出下一条建议问题。输入框为空时按 **Tab** 接受建议；只有你主动发送，它才会真正进入对话。

## 对话归档在主题下面

学习会话是绑定精通之路的普通对话。侧栏按主题归档；重新打开会恢复地图和路标。普通 Chat 也可给出交接卡，继续或新开会话；仅在你点击后跳转。

## 把目标写成可验证的能力

与其写“学微积分”，不如写“在大一考试题中选择并使用换元或分部积分，并解释方法为何成立”。加入对应章节或已保存的来源记录，学习前审阅大纲。让导师聚焦一个知识点，自己作答，再用自己的话解释结果；只看懂答案并不足以证明概念或设计能力。

路径及学习对话属于当前工作区。重开主题可恢复地图与会话，通过到期复习入口回顾旧依据。自主声明与评估结果会区别记录，阅读进度环时应保留这个区别。练习补充题目层面的回忆训练，学习笔记本保留自己的解释。
