交互式书本把你的材料变成一本**「活书」**（living book）——不是静态 PDF，而是一个由「带类型的块」搭起来的阅读环境：你可以对它测验、把它当动画看、当作可操作的实时组件来玩，并逐页与它对话。

## 它在哪里

从左侧栏的**学习 → 书籍**进入。书库同时展示个人书与获准访问的管理员共享书；学习者账号需明确获得书籍入口权限，共享书还需对应的书籍权限。只有获准创建个人书时才显示 **New book**。

![当前工作区的书籍](/screenshots/dev/books.png)

## 创建流程

1. 如果显示 **New book**，打开 **Book → New book**。
2. 选择一个**主题**与**来源**——知识库、笔记本、题库或聊天历史。
3. 在编译前审阅生成的**提案**（章节大纲）。编辑器会显示由编译器模板推导的**逐章实时成本预估**，并随章节的增删或类型调整而更新。选好允许生成的内容类型后，再选择 **Generate all chapters** 或 **First chapter only**；只有前者会把整份章节骨架全部排入队列。
4. 让引擎为每一章生成页面规划与块。
5. 阅读、批注、自测，或在页面旁对话。

编译的生命周期比启动它的那个请求更长：`confirm_spine` 在页面壳建好后就返回，而它排下去的活儿还要跑上几分钟；事件流按**书**归属，所以你可以看着这本书被写出来，刷新或断线重连都不会中断。

书会追踪来源的**指纹**（fingerprints），因此当某个知识库在编译后发生变化时，维护命令能报告这种漂移（见下文）。

## 阅读体验

一章书由**带类型的块**（typed blocks）搭成。关键在于：每个块都是承载某个想法的*恰当*媒介——一个概念变成一道测验，一段推导变成一段动画，一个过程变成一个交互组件。

**测验块与闪卡块**把一节内容变成主动回忆。答案在你点开前一直隐藏，右侧的逐页大纲让长章节始终好导航。

![包含测验的书籍页面](/screenshots/dev/book-quiz.png)

**动画块**把渲染好的视觉内容直接嵌进页面；安装相应附加组件后也包括 Manim 视频——当一段推导*看*比*读*更易懂时尤其有用。


**交互块**是实时的 HTML 组件。这里，滑块会实时改变采样频率比例——读者是在「操作模型」中学习，而不只是「读到」它。

Figure 与 interactive 块使用和主页 Visualize 相同的 `deeptutor.visualization/v1` 结果封装与沙箱 viewer，因此 SVG、Mermaid、图表和 HTML 交互在书页与独立可视化之间保持一致。

![交互式书籍页面](/screenshots/dev/book-widget.png)

**图表块**就地渲染 Mermaid / 概念图，而每一页都有一个 **Page Chat**（页面对话）——就你正在读的内容提问，得到锚定于该页的答复。


读过的页面、书签与测验作答汇总为完成度分数和薄弱章节。选中一段文字可把它送进待审阅的 **Learning capture inbox**，再批准或拒绝是否转成学习材料；每本书都可导出为 Markdown。暂停长编译时会先持久化状态，再取消排队与进行中的工作并保留已完成页面；刷新或重启后仍保持暂停，只有你明确点击继续才会恢复。

管理员共享书的标准章节内容存放在 admin 工作区；每位读者的进度、书签、测验作答、learning capture 与 Page Chat 关联则留在自己的工作区并保持私密。

## 编排与自定义

个人书以及拥有 **edit** 权限的共享书可以编辑，并非定格。用 **Insert block**（插入块）在章节任意位置加块——并从完整调色板里选类型：text、callout、quiz、code、timeline、flash cards、figure、interactive、animation、deep dive、user note。只读共享书不会显示这些编排控件。


拥有 edit 权限时，悬停块即可**移动、重新生成、删除或切换类型**。只有 text 与 callout 这类纯文字块显示 **Edit text**，user note 有自己的编辑器；结构化块必须重新生成。共享编辑使用 revision 检查；若协作者先提交造成冲突，请刷新重试。共享删除仍只允许 admin。


## 来源怎么选

| 来源 | 适用于 |
| --- | --- |
| **知识库** | 想要有依据的教材/论文内容。 |
| **笔记本** | 已有整理好的笔记或先前的摘要。 |
| **题库** | 想要以练习为中心的页面。 |
| **聊天历史** | 想把一段辅导会话变成学习材料。 |

## 维护

```bash
deeptutor book list
deeptutor book health <book_id>
deeptutor book refresh-fingerprints <book_id>
```

## 工作区与第一本书

书籍属于当前工作区。可以新建 `概率论要点`，选择实际需要的讲义知识库和保存记录，编译前检查章节结构。先生成第一章，确认深度、符号与来源覆盖后再决定是否生成全书。阅读时向页面导师询问不清楚的推导，把精炼解释放进收藏夹；回忆训练交给练习，需要能力证明时使用精通之路。

来源选择器可能仍用 **Notebook** 指收藏夹的保存集合，与 `/co-writer` 中可编辑的学习笔记本不同。生成书籍是新写出的读物，选择了来源不代表每句都准确；重要结论应检查引用并对照原文。
