**学习笔记本**是工作区内的写作与思考空间。从**主页 → 学习笔记本**进入 `/co-writer`，这也是原 **Co-Writer** 的地址。当前编辑器采用页面与内容块，Dito 在页面旁陪伴；不再是旧版 Markdown 源码与预览分栏界面。

![学习笔记本页面与 Dito](/screenshots/dev/notebook-detail.png)

## 创建与组织页面

1. 为主题、课程或论文选择**新建页面**，也可用**导入 Word**导入 `.docx`。
2. 命名页面并写下首批内容块，通过页面树创建子页面与切换页面。
3. 置顶常用页面。笔记本首页搜索覆盖页面与子页面的标题和预览文本。
4. 离开前检查页头保存状态；保存失败时先处理错误，不要把屏幕上的草稿当作已安全存储。

页面可以设置图标、封面与父页面。大主题适合设为顶层页，再为定义、证明、练习创建子页。删除父页面会将子页上移一级；删除页面本身需要确认。

## 在正在思考的位置询问 Dito

选中文段或聚焦内容块，打开 Dito。可使用**解释这段**、**改写**、**缩短**、**举个例子**、**翻译**或**考考我**；空行也能作为续写起点。对话与页面及相关行或内容块关联，之后可从页面对话列表重开。

回答可以插入行下供审阅，也能另存为子页面。修改提议以建议形式出现，可审阅、接受、忽略或继续讨论。目标块已被修改时，会保留你的编辑，并要求重新讨论过时建议，便于分清自己采纳了哪些修改。

![与笔记页面关联的 Dito 对话](/screenshots/dev/notebook-dito.png)

## 将来源带入自己的写作

使用**插入收藏**搜索、预览并插入[收藏夹](/zh-cn/learning-workspace/favorites/)中的原始记录，也可请 Dito 将多个收藏整理成带引用的笔记。来源插入与知识库操作帮助笔记依据可回看的材料。

例如新建 `条件概率`，插入保存的解释，再写自己的反例。请 Dito 检查论证并建议更清楚的段落，审阅后再应用；另建 `练习` 子页，记录这个主题引出的题目。

## 在页面内学习

笔记可容纳测验、闪卡、图示及其他受支持的生成学习块。在相关行让 Dito 创建学习活动，查看生成结果；需要另一个版本时使用内容块菜单。生成取决于所需能力和模型是否可用。保存的学习块是页面的一部分，再次查看它与重新生成是两件事。

## 导出与复用

页面菜单支持导出 **Markdown** 或 **Word**。Word 保留文字与来源链接，互动块会变成静态内容；提交或分享前应检查导出结果。收藏夹适合存放原始来源，学习笔记本适合保存自己的综合理解、结构和学习活动。

笔记页面属于当前工作区，切换工作区会改变页面库。[个性化](/zh-cn/learning-workspace/memory/)可跨工作区影响助手的帮助方式，而页面内容留在所属项目。
