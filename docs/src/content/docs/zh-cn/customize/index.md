description: 账号级的人格、技能和连接，与工作区是什么关系。

---

**个性化**是账号这一层的架子。工作区放的是工作本身：对话、学习活动和材料。架子上是换工作区之后仍然带着的做法。工作区仍然决定一轮可以使用其中哪些资源，对话还可以再收窄。架子上的东西对另一个账号不可见。

| 放在这里 | 它是 |
| --- | --- |
| [人格](/zh-cn/customize/personas/) | 一轮对话的语气和回答策略 |
| [我的智能体](/zh-cn/customize/agents/) | 一个已连接的 harness，或一份可以咨询的导入记录 |
| [技能](/zh-cn/customize/skills/) | 任务需要时模型去读的可复用步骤 |
| [MCP 服务](/zh-cn/customize/mcp/) | 远程服务器上的工具，授权记在账号上 |
| [CLI 应用](/zh-cn/customize/cli-apps/) | 管理员安装的程序，在沙箱里运行 |
| [记忆](/zh-cn/learning-workspace/memory/) | 你可以打开并改正的偏好和摘要 |
| [EduHub](/zh-cn/customize/eduhub/) | 导入前先检查的社区技能 |

检索不是这些账号对象之一。[RAG 集成](/zh-cn/customize/rag/)属于某个知识库，以及这个库索引的文件。

每条路径的信任边界不同。技能是说明文字。MCP 服务是远程工具边界。CLI 应用是宿主机上的代码。EduHub 分发技能，并不运行它们。工作区的分配引用账号目录，不复制凭据，也不绕过按用户的授权。

伙伴可以从一个人格开始，然后保有自己的灵魂、资料库和渠道。那是伙伴自己的身份，之后修改人格不会改写它。见[渠道](/zh-cn/channels/)。
