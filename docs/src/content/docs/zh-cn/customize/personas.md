人格是账号级预设：名称、一行描述，以及关于语气和教法的 Markdown 说明。你选的能力仍然决定任务。人格只改变这个任务怎么被完成。

## 创建一个并试一次

1. 打开 **个性化 → 人格**。
2. 新建预设。写下名称、一行描述，以及你可以检验的行为。“给出解答之前，先问我下一步”是一条能用的说明。
3. 保存。
4. 在[对话](/zh-cn/learning-workspace/chat/)的输入框里选中这个人格，提一个短问题。
5. 回复没有遵守说明时，改预设再问一次。不再需要时删除预设。

`Default` 是不加设定的助手。**peer**、**research-assistant**、**teacher** 这些内置人格在你创建自己的之前就可以用。共享部署里，部署预设对普通用户只读。你自己的同名人格优先。

同一个预设可以作为伙伴灵魂的起始文本。创建伙伴时会复制它。之后修改人格不会改变那个伙伴。在[渠道](/zh-cn/channels/)里连接伙伴。
