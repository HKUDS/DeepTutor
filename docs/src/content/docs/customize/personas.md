A persona is an account-level preset: a name, a short description, and Markdown instructions for voice and pedagogy. The capability you select still decides the task. A persona only changes how that task is carried.

## Create one and try it

1. Open **Personalization → Personas**.
2. Create a preset. Name it, add a one-line description, and write behavior you can test. “Ask for my next step before showing a solution” is a usable instruction.
3. Save.
4. In [Chat](/learning-workspace/chat/), choose that persona in the composer and ask one short question.
5. If the reply ignores the instruction, edit the preset and ask again. Delete the preset when you no longer want it.

`Default` is the plain assistant. Built-ins such as **peer**, **research-assistant**, and **teacher** are available before you create your own. On a shared deployment, deployment presets are read-only for ordinary users. Your own persona with the same name takes precedence.

The same preset can be the starting text for a partner's soul. Creating the partner copies it. Later edits to the persona do not change that partner. Connect the partner in [Channels](/channels/).
