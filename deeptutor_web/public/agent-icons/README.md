# Official connected-agent icons

These files are local copies of the projects' own icon assets so connected-agent
menus keep working offline. Do not redraw or substitute them with approximations.

- hermes.svg embeds the exact PNG bytes from NousResearch/hermes-agent at
  website/static/img/favicon-32x32.png.
- openclaw.svg is copied from openclaw/openclaw at
  docs/assets/pixel-lobster.svg, the logo configured by its documentation site.
- deepseek-harness.svg is copied from deepseek-ai/deepseek-harness at
  apps/web/public/favicon.svg.
- kimi.svg embeds the exact PNG bytes from MoonshotAI/kimi-cli at
  web/public/logo.png, the logo loaded by Kimi CLI's own web app.
- opencode.svg is copied from anomalyco/opencode at
  packages/identity/mark.svg.
- mimo-code.svg embeds the exact SVG bytes served by Xiaomi MiMo's official
  MiMo Code page at /static/mimo-code.a1594b207bbc4bee.svg.

Brand and trademark rights remain with their respective owners.
