# 工作区与学习数据

普通对话在输入框选择或新建工作区；书籍、掌握路径、沉浸式阅读、沉浸式观看在开始弹窗选择工作区。任务的资料、会话、进度、练习记录和生成文件都保存在所选工作区，未选择时使用「默认工作区」。侧栏历史与个性化学习首页汇总当前账号的各工作区记录，打开记录时进入它所属的工作区。

升级后，原有学习数据保留在原来的目录，统一属于默认工作区。旧版给对话设置的文件夹绑定不会自动拆分历史资料；需要重新整理时，使用「设置 → 个人 → 数据迁移」。

## 存放位置

| 内容 | 存放方式 |
| --- | --- |
| 默认工作区的数据 | 保留历史 `data/user/workspace/`、`data/user/chat_history.db` 等路径；多用户使用各自的数据根目录。 |
| 自建工作区的数据 | 工作区文件夹内的 `.deeptutor/data/`，包括独立会话数据库、学习资料、进度和缓存。 |
| 便于查看的生成文件 | 工作区文件夹内的 `outputs/`，按功能、会话和轮次组织。 |
| 设置、凭据、工作区登记信息 | 属于用户账号，切换工作区不改变。 |
| 记忆 | 仍由账号共享，本次不按工作区隔离。 |
| 系统工作区 | 脱敏配置快照、Skill 和 MCP 概览，不用于学习会话。 |

模型工具不能通过工作区文件浏览入口读取 `.deeptutor` 内部数据库。管理员明确共享的书籍和知识库继续遵守原有共享权限；个人学习进度按工作区分别保存。管理员迁移共享目录前需先处理相关授权，预览会提示；也可以直接导出副本。

## 创建、切换与归档

在「设置 → 个人 → 工作区」创建、重命名或归档工作区。没有自建工作区时，输入框与学习开始弹窗仍提供选择和新建入口。可以使用自动创建的目录，也可登记已有文件夹；远程部署填写的是服务器路径。

切换会重新加载当前页面，清空旧工作区的界面缓存。已启动的回复和资料处理任务继续写入启动时的工作区。任务页面和文件链接携带工作区信息，首页和设置不继承之前的选择。跨工作区打开记录前，未发送的文字及附件暂存于该浏览器的原工作区草稿；在新对话输入框指定工作区时，草稿随之转移。

已有普通对话可以移动到另一个工作区，关联子对话、附件和产物一起移动。有学习资料或其他会话依赖时，使用数据迁移预览完整关联内容。运行中的会话不能移动。归档保留内容并阻止新写入，恢复后可继续学习。

## Partner 绑定工作区

新建 Partner 的「资料库」步骤可以选择已有工作区，配置页也可以更改绑定。绑定后持续共享该工作区的文件、知识库、技能和笔记本，生成文件写入该工作区的 `outputs/`；工作区的资源分配规则和 Partner 的工具开关同时生效。Soul、对话记录和 Partner 记忆保持独立。更改绑定从下一条消息开始生效。

默认仍使用「Partner 私有工作区」，可挑选知识库、技能和笔记本复制进去。切换到共享工作区不会删除之前的私有资料，解除绑定后可继续使用。知识库选择列表不包含 sub-agent 等无法供 Partner 检索的连接。已归档、不可用或不属于 Partner 所有者的工作区不能绑定；已绑定的工作区不可用时，Partner 会报错，不会自动改用其他工作区。

## 数据迁移与导出

打开「设置 → 个人 → 数据迁移」，选择来源、目标及功能，然后预览。预览包含文件数量、体积、相关会话、自动加入的依赖和不能迁移的原因。移动来源数据时，引用它的书籍、学习路径或对话也可能需要一起移动；请以预览列出的范围为准。

迁移以功能存储为单位。已有目标功能数据或数据库 ID 冲突会阻止迁移，不会覆盖；此时可创建空工作区作为目标。仅打开页面产生的空数据库不算已有学习数据。无冲突的普通会话可移入已有工作区。

迁移会保留源数据快照，使用 SQLite 备份接口复制数据库，并校验文件内容。所有目标内容验证完成后才清理源数据。关闭网页不会取消已开始的迁移。发生中断时可在最近操作中点击「恢复迁移」：提交前恢复原状态，提交后完成清理。待恢复操作会阻止学习数据继续写入，设置页面仍可使用。

历史目录会在发现列表中显示。已经支持的历史学习格式继续使用各功能原有的升级逻辑；额外旧目录可导出，或作为历史档案保存在目标工作区的 `historical/` 数据目录，保留原文件，不自动混入当前学习记录。导出 ZIP 包包含所选数据、依赖与校验清单，不包含账号设置和凭据。记忆不属于迁移范围。

恢复副本保存在账号私有运行目录的 `data-migrations/` 下，界面显示具体路径。成功迁移后也保留副本。数据量较大时，应为复制和备份预留磁盘空间，并暂停外部程序对这些目录的写入。

## 更改文件夹位置

「工作区 → 迁移目录」改变工作区文件夹位置，工作区 ID 保持不变。修改根目录只迁移跟随根目录的工作区，单独登记的文件夹不随之移动。目标文件夹必须不存在；复制校验后更新登记信息，原文件夹保留为备份。

默认工作区为兼容历史数据保留原存储路径；其文件夹位置设置影响展示给模型的文件和 `outputs/`。若要将默认工作区的完整学习数据放进一个自建目录，应使用「数据迁移」。

## CLI 与 Python SDK

```bash
deeptutor run chat "解释傅里叶变换" --workspace ws_...
deeptutor chat --workspace ws_...
```

CLI 不指定 `--workspace` 时使用默认工作区。

```python
from deeptutor.app import DeepTutorApp

app = DeepTutorApp(workspace_id="ws_...")
sessions = await app.list_sessions()
```

也可使用 `deeptutor.services.workspace.context.workspace_context(workspace_id)` 包裹 SDK 或服务调用。HTTP 使用 `dt_workspace` 查询参数或 `X-DeepTutor-Workspace` 请求头；WebSocket 建立连接时固定范围。自建工作区必须已登记且属于当前账号。


## 分配 Skills、MCP 和知识库

「学习空间」统一管理资源。「设置 → 工作区」在新建或编辑工作区时，可以分别为 Skills、MCP 服务和知识库选择「继承原有可用资源」或「仅使用所选资源」。选择后一种方式但不勾选任何项目，表示该工作区停用这一类资源。取消分配不删除资源、凭据、已有对话或学习记录；更改从后续轮次开始生效。

旧工作区无需迁移，未保存分配配置时继续使用原有规则：Skills 和 MCP 沿用账户权限，知识库保留当前工作区的原有目录和管理员授权。共享知识库通过选择资源库中的条目分配，索引不复制、不搬动；相同名称的知识库按来源区分。共享知识内容的同时，各工作区的学习记录仍分别保存。

技能页面可切换「账户共享技能」与某个工作区的专属技能。专属技能保存在该工作区的 `skills/` 下，在已启用的同名技能中优先于账户共享、管理员分配和内置版本。摘要、自动注入正文和按需读取都使用相同的解析结果。MCP 的连接配置及凭据继续由账户管理，工作区只保存服务引用，不能扩大管理员授予的权限。

知识中心集中显示账户及各未归档工作区的知识库，并标注来源；新建资源默认进入账户资源库。删除资源前会列出引用它的工作区。资源删除或失去访问权限后不会自动启用其他资源，分配设置中会提示失效条目。移动工作区文件夹保留其资源引用；若迁移整个知识库数据到另一工作区，须先解除相关分配，或选择导出副本。

工作区分配控制 DeepTutor 暴露和调用哪些 MCP 服务。外部服务自身的文件、数据库和远程账号权限仍由该服务配置决定；分配不会自动改变其进程、根目录或远程授权。
