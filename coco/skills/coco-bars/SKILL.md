# 平均数分步柱形图（coco-bars）

孩子看过的课程视频，讲平均数时都用同一套柱形图：每组一根柱，**柱宽代表人数，柱高代表平均数**；绿色虚线是平均线；柱子高出平均线的部分是「多出的」（蓝色），柱顶到平均线之间的空缺是「缺的」（橙色虚线框）。讲平均数题时，用下面的代码块画同样的图，前端会把它渲染成可以「上一步 / 下一步」的分步图。

## 什么时候画

- 孩子问平均数题的思路、问「为什么要乘人数 / 为什么要除以几」、某一步看不懂时：画。
- 一次回答最多画 1 张图。只是简单对答案、闲聊时不要画。

## 怎么写

在回答中插入一个语言标记为 `coco-bars` 的代码块，内容是**严格 JSON**（双引号、不要注释、不要尾随逗号）：

````
```coco-bars
{ "title": "...", "unit": "厘米", "groups": [...], "steps": [...] }
```
````

### groups：有几组（1–6 组）

| 字段 | 必填 | 含义 |
|---|---|---|
| `id` | 是 | 英文短名，步骤里引用，如 `"low"` |
| `name` | 是 | 显示名，如 `"矮个段"` |
| `value` | 是 | 这一组的平均数，决定柱高 |
| `count` | 否 | 人数，决定柱宽。人数未知就不写 |
| `countLabel` | 否 | 柱下文字，人数未知时写 `"?人"` |
| `valueLabel` | 否 | 平均数未知时，`value` 填一个合理的示意高度，这里写 `"?"` |

### steps：分几步揭晓（建议 3–6 步，最多 10 步）

每一步在前一步的图上**追加**内容。每步只讲一件事。

| 字段 | 含义 |
|---|---|
| `say` | 必填。这一步配的一句话，最多 120 字。前几步用**提问**引导，不要提前说出答案 |
| `lines` | 平均线：`{"value": 155, "label": "中＋高 平均155", "groups": ["mid","high"]}`。`groups` 不写时横跨所有组 |
| `blocks` | 多出或缺的部分：`{"group": "high", "from": 155, "to": 163, "label": "每人多8"}`。`from`、`to` 是同一刻度上的两个数值 |
| `moves` | 移多补少的箭头：`{"from": "high", "to": "low", "label": "补576"}` |
| `braces` | 组上方的括号：`{"groups": ["mid","high"], "label": "超过130的同学"}` |
| `formula` | 这一步的算式，会累积显示在图下方，如 `"72 × 8 ＝ 576"` |
| `focus` | 要高亮的组 id，如 `["mid"]` |

`blocks` 的颜色自动判断：在柱子里面、平均线以上的部分是「多出」（蓝）；柱顶以上、到平均线为止的空缺是「缺的」（橙色虚线）。如果要标出夹在两条线之间的一段（例如「每人 7 厘米」），写 `"kind": "band"`（黄色）。

## 讲法要求

- 和视频保持一致：先画平均线 → 看每人差多少 → 在柱下写人数 → **每份差 × 人数 ＝ 总差**，多出的总量等于缺的总量。
- 所有数字和算式必须正确，画图前先自己验算一遍。
- 代码块外的文字只写 1–3 句，并以一个引导孩子思考的问题结尾，不要把图里的步骤再用文字讲一遍。

## 示例（第11讲 第4集 探索6：全校身高分三段，求中间段人数）

```coco-bars
{
  "title": "中间段为什么要 ÷7",
  "unit": "厘米",
  "groups": [
    {"id": "low", "name": "矮个段", "count": 99, "value": 122},
    {"id": "mid", "name": "中间段", "countLabel": "?人", "value": 151, "valueLabel": "?"},
    {"id": "high", "name": "高个段", "count": 72, "value": 163}
  ],
  "steps": [
    {"say": "全校按身高分成三段，中间段人数不知道。你先在柱子下面写上人数。", "focus": ["mid"]},
    {"say": "第一种分法：中间段＋高个段，平均155。高个段每人比155多几？",
     "lines": [{"value": 155, "label": "中＋高 平均155", "groups": ["mid", "high"]}],
     "braces": [{"groups": ["mid", "high"], "label": "超过130的同学"}]},
    {"say": "高个段每人多8。只算了一个人，高个段有几个人？一共多多少？",
     "blocks": [{"group": "high", "from": 155, "to": 163, "label": "每人多8"}],
     "moves": [{"from": "high", "to": "mid", "label": "补给中间段"}],
     "formula": "72 × 8 ＝ 576"},
    {"say": "第二种分法：矮个段＋中间段，平均148。矮个段每人少几？一共少多少？",
     "lines": [{"value": 148, "label": "矮＋中 平均148", "groups": ["low", "mid"]}],
     "blocks": [{"group": "low", "from": 122, "to": 148, "label": "每人少26"}],
     "formula": "99 × 26 ＝ 2574"},
    {"say": "看中间段：每人身上148到155这7厘米，被两条线切成上下两截。所有人的这两截合起来是多少？",
     "blocks": [{"group": "mid", "from": 148, "to": 155, "kind": "band", "label": "每人7厘米"}],
     "formula": "2574 ＋ 576 ＝ 3150", "focus": ["mid"]},
    {"say": "每人7厘米，一共3150厘米，中间段有几个人？", "formula": "3150 ÷ 7 ＝ 450（人）"}
  ]
}
```
