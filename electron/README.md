# DeepTutor Desktop

Desktop application for DeepTutor.

## Development

```bash
cd electron
npm install
npm run dev
```

## Build

```bash
npm run dist:mac   # macOS
npm run dist:win   # Windows
npm run dist:linux # Linux
```

## Features

- Embedded Python backend (no separate installation required)
- System tray support
- Auto-update
- Secure API key storage (system keychain)
