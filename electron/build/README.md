# Build Assets

## Icons

Place icon files here:
- `icon.png` - 256x256 PNG for macOS/Linux (electron-builder will convert)
- `icon.ico` - Windows icon (electron-builder will convert from PNG)

For development, you can use the SVG at `../assets/icon.svg` as a source.

## Entitlements

- `entitlements.mac.plist` - macOS sandbox entitlements for notarization
