# DeepTutor v1.6.14 Release Notes

**Release Date:** 2026.10.08

Building on [v1.6.13](ver1-6-13.md), v1.6.14 brings original-source visual practice, recoverable knowledge-base indexing, scientific research tools, and managed plugins. Video learning now lives in Reading; existing Watching conversations migrate when reopened.

## What's New

### Original figures, pages, and visual practice

Ask about an exact figure, table, or PDF page in an attached knowledge base. DeepTutor retrieves the original image or renders the selected page or region, preserving document identity and source links. The Files view exposes source visual coverage, including missing or unverified extraction. Guided Learning uses this evidence for visual questions and distinguishes explanations, assisted practice, and independent mastery; inaccessible or uncertain evidence stays ungraded.

### Indexing that can recover

Knowledge-base details show durable indexing progress, individual source outcomes, and recovery information. Retries reuse compatible completed parses and validated MinerU cloud slices; cancellation takes effect at a safe boundary. LlamaIndex publishes a new version only after reload, vector validation, and a retrieval probe succeed, preserving an earlier queryable version when a rebuild fails. Retrieval also reports hybrid-to-vector fallback and incomplete IMA evidence.

### Reading includes video learning

YouTube and Bilibili media share the Reading workspace, with timestamp-grounded discussion and native playback. Previous Watching conversations, positions, and notes can be imported without modifying their legacy media or notebook records. Reading panels resize independently, offer a focus preset, and retain usable pagination and selection controls on narrow screens.

### Research with traceable evidence

Scientific requests and Deep Research gain tools for reading versioned arXiv papers and original pages, checking paper claims against a pinned GitHub revision, and building literature evidence matrices. The MCP catalog adds alphaXiv. Administrators can approve an exact private-network MCP origin for account-owned research connections, with approval checked again when tools run.

### Reviewed plugin lifecycle

The plugin CLI supports inspection, installation, permission approval, enable/disable, rollback, and uninstall. Managed wheels run in separate environments, with artifact checks and revocable runtime gates. The official catalog format supports reviewed packages; this release ships an empty catalog, so it does not install new third-party code automatically.

### Learning continuity and everyday fixes

Space gains a workspace learning journal showing the current mission, last-session handoff, and confirmed learning records. Chat retries reuse the original conversation after a lost acknowledgement, parked questions survive reloads, and unsent drafts remain recoverable. Branch navigation, memory account isolation, launcher recovery, and error reporting improve; Visualize also gains Mermaid mindmaps.

### Providers and setup

GitHub Copilot uses device login and per-owner credentials, with inference checked during setup. Opper joins LLM and embedding providers, and Y-API joins LLM providers. Provider settings offer a clearer add flow, protocol-aware default endpoints, and provider voice discovery. Local embedding services can work without API keys, while embedding concurrency and Qwen3-Instruct thinking handling are corrected.

Updated English and Chinese documentation accompanies the release at [deeptutor.info](https://deeptutor.info/).

## Upgrade Notes

Run `pip install -U deeptutor`; Docker users pull `ghcr.io/hkuds/deeptutor:latest`.

- **Video learning:** use Reading for new video sessions. The standalone `immersive_watching` capability and `watching` / `watch` CLI aliases are retired. Existing Watching links enter the compatibility migration; keep the existing application data available. A missing legacy video leaves its conversation accessible as ordinary chat.
- **GitHub Copilot:** run `deeptutor provider login github-copilot` again if you previously relied on external Copilot/nanobot token files. Each account signs in separately; Copilot profiles cannot be shared through model grants.
- **Speech:** explicitly select a voice in the model settings; new profiles no longer receive a hard-coded default voice.
- **OrcaRouter:** its built-in provider presets are removed. Configure a Custom connection with an explicit compatible endpoint and model if you still use that service.
- **Knowledge bases:** older indexes need re-parsing and reindexing to gain newly extracted figure records. Exact PDF-page inspection can use the original document directly. Retry reuses only valid compatible checkpoints; it does not resume an interrupted local MinerU inference midway through a document.
- **Plugins:** review requested permissions before approving a managed package. Restart DeepTutor when a plugin generation changes so the reviewed code is loaded; disabling or revoking approval blocks subsequent calls.
- **systemd installs:** stop the service, upgrade DeepTutor in its Python environment, and restart the service.
