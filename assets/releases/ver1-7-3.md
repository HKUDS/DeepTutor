# DeepTutor v1.7.3 Release Notes

**Release Date:** 2026.11.16

Building on [v1.7.2](past_releases/ver1-7-2.md), v1.7.3 makes reading and book editing more flexible, expands search and agent connections, and improves learning records, model streams, and desktop upgrades.

## What's New

### Read, zoom, and revisit question help

The PDF reader adds continuous zoom, text-fit controls, and an image viewer. Annotation updates and multi-material selection are more reliable. Reading quizzes keep answer keys on the server and preserve question-linked help separately from attempts; authorized guardians can review reading progress, quiz records, and help activity.

### Review book changes before applying them

Edit generated chapters and sections without rebuilding the whole book. Structure changes and page-chat proposals show a reviewable diff before application, and the most recent unchanged edit can be undone. New empty sections generate when opened; math rendering and page-chat continuation also receive fixes.

### More search providers and connected agents

Search adds DeepSeek, SpecStream, and SearchApi, including SearchApi web, news, and scholar modes. Web Fetch gains a selectable DeepSeek backend, and Standard Compute joins model setup. A configured Agent Client Protocol (ACP) process can be consulted as a local subagent. MCP OAuth refresh and reconnection are more reliable after consent and restarts.

### Conversations and practice retain their context

Choose supported reasoning effort per conversation. Untouched chat sessions inherit ready workspace knowledge bases, saved side-chat tabs reopen for the same account, and question-bank sources support search and pagination. Mastery fixes preserve explanations across failed attempts, keep issued questions gradable after re-indexing, and improve reference answers and narrow-screen navigation.

### Better document parsing and language support

Docling preserves structured page content and exposes optional formula and picture enrichments. Upload validation follows the available parser formats, GitHub knowledge sources accept MDX, and retrieval respects exact source paths. Italian and Hungarian join the interface and reply-language options, while Hindi becomes a reply language.

### More reliable model streams and desktop upgrades

Provider calls handle stalled streams, incomplete terminal events, tool identifiers, and replayed reasoning more carefully. History that still exceeds its plan after condensation stops with a clear error. Installing a newer desktop app adopts its newer bundled core with backup and rollback; macOS Finder launches also discover host CLIs in common install locations. Launcher and updater readiness waits respect configured limits.

## Upgrade Notes

- **Full app:** stop DeepTutor and back up the runtime home, then run `python -m pip install --upgrade "deeptutor[full]==1.7.3"`. Keep the same `DEEPTUTOR_HOME`; verify with `python -m pip check` and `deeptutor module list` before restarting. Additional feature wheels must also match 1.7.3.
- **Legacy installations:** versions 1.6.15 and earlier require uninstalling the old `deeptutor-cli` package before installing the modular family. Use the manual migration in [v1.7.0](past_releases/ver1-7-0.md); an old update worker cannot acquire the new migration logic retroactively. Recover a full app with optional parsing using `"deeptutor[full,parse]==1.7.3"` in the same environment.
- **Source and Docker:** source users install `requirements/full.txt`, then `python -m pip install -e . --no-deps`, and refresh `web/` with `npm ci --legacy-peer-deps` on Node.js 22. Docker users pull `ghcr.io/hkuds/deeptutor:1.7.3` or `:latest` and recreate the container with its existing data volume.
- **Desktop:** use the matching Apple Silicon or Intel DMG, Windows installer, or portable ZIP. Windows builds remain unsigned. Automatic update discovery is not connected; replacing the app now trials a newer bundled core and preserves a workspace backup.
- **Embeddings:** indexed OpenAI-compatible embedding responses are now restored to input order. If a gateway previously returned reordered vectors, rebuild affected indexes to correct their text/vector associations; existing index files are preserved.
- **Book editing and ACP:** pause book generation before structural edits. ACP requires a configured agent command and its own authentication; interactive elicitation and permission requests are not supported by this initial client.
- **Provider recovery:** the default remains `store=false`. Recovery of an already-known response is limited to the official OpenAI Responses endpoint when the request already opted into `store=true`; unresolved operations pause instead of automatically submitting replacement work.
