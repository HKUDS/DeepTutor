# DeepTutor v1.7.0 Release Notes

**Release Date:** 2026.10.28

Building on [v1.6.15](past_releases/ver1-6-15.md), v1.7.0 brings modular installation, a refreshed learning workspace, block-based notebooks with Dito, and narrated video lessons. Full-app upgrades now use `deeptutor[full]`; existing runtime data remains separate from the installed packages.

## What's New

### Install the parts you use

`deeptutor` now provides core chat, CLI, and SDK; `deeptutor[full]` selects the Web app and standard feature modules. The `deeptutor-cli` package becomes a compatibility alias. Inspect installed, enabled, and ready states with `deeptutor module list`, then enable, disable, install, or remove modules while the app is stopped. Dependency checks protect required modules, and removal preserves user data.

### A workspace organized around learning

Modern and Classic layouts offer different navigation arrangements. Home brings together Chat, the Task Board, Learning notebook, and Calendar; Learning and Resources keep study activities and materials accessible. Customize Chat modes, controls, and starting prompts, or choose which learning methods appear on the New learning page. Conversation and resource navigation retain their workspace boundaries.

### Notebook pages with Dito beside them

The Learning notebook replaces the former Co-Writer editor with pages, subpages, and blocks. Import Word documents, insert source records from Favorites, discuss a passage with Dito, and review proposed edits before accepting them. Export pages as Markdown or Word. Favorites hold saved source records; notebook pages hold your own writing and understanding.

### Video lessons and free read-aloud

Choose Video Lesson to generate a lesson that plays directly in the browser, with captions and optional Microsoft Edge narration. Frame checks execute generated code inside a bounded WebAssembly interpreter; Docker is not required. Microsoft Edge also joins the read-aloud providers, and reply playback is more reliable on iOS.

### More reliable tutoring and indexing

Compatible interrupted LlamaIndex rebuilds can resume completed embedding checkpoints. Knowledge-base creation retains same-named documents, and one failed caption group no longer aborts the entire ingestion. Chat recovers worker failures more consistently, completed Anthropic thinking is excluded from history replay, and prompt caching uses steadier conversation prefixes. Guided Learning preserves mathematical meaning when checking citations and keeps review work within its eligibility gate.

English and Chinese guides are synchronized with this release at [deeptutor.info](https://deeptutor.info/).

## Upgrade Notes

- **Full app:** stop DeepTutor and back up the runtime home, then run `python -m pip install --upgrade "deeptutor[full]==1.7.0"`. Run `python -m pip check` and `deeptutor module list` before restarting with the same `DEEPTUTOR_HOME`. Bare `deeptutor` now selects core only.
- **Legacy CLI package:** first run `python -m pip uninstall deeptutor-cli`, then install the new core or full profile. Optionally reinstall `deeptutor-cli==1.7.0` as the compatibility alias. The old CLI owns shared Python files, so upgrading it in the same transaction can remove files needed by the new core. Package removal leaves runtime-home data intact.
- **Source installs:** install `requirements/full.txt`, then `python -m pip install -e . --no-deps`. Use `python scripts/install_extras.py <extra>` for optional source dependencies. Source checkouts support module enable/disable; package install/uninstall requires a wheel environment.
- **Docker:** pull `ghcr.io/hkuds/deeptutor:1.7.0` or `:latest` and recreate the container with the existing data volume.
- **Video Lesson:** the backend needs Node.js 22+ and npm; first use downloads pinned rendering packages. Install the `edge-tts` extra for narration. Without available narration, lessons retain their captions and play silently.
- **Module versions:** core and feature wheels must match. Stop active servers and CLI turns before changing modules; inspect dependency blockers rather than uninstalling packages beneath a running app. See [module installation and migration](../../docs-for-dev/MODULES.md).
