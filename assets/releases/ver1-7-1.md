# DeepTutor v1.7.1 Release Notes

**Release Date:** 2026.11.01

Building on [v1.7.0](ver1-7-0.md), v1.7.1 introduces Open DeepTutor desktop previews, broader localization, and substantial improvements to chat, lessons, accounts, providers, and document handling. Existing runtime data stays in place; no manual migration is required.

## What's New

### Open DeepTutor desktop previews

Open DeepTutor bundles Python, Node.js, and the full learning workspace into a desktop app for Apple Silicon Macs, Intel Macs, and Windows x64. Preview builds are available from the Desktop Release workflow, with DMG downloads for macOS and Setup or portable ZIP options for Windows.

### More languages and account controls

Vietnamese, Japanese, Turkish, and Brazilian Portuguese join the interface and reply-language options, alongside expanded translations, regional date formatting, and right-to-left rendering. Account-scoped learning text controls adjust font size and line spacing. Users can change their passwords from Profile, while accounts still using an admin-assigned temporary password receive a change prompt.

### Chat that keeps your work and sources together

Unsent composer drafts survive navigation, and conversational creation drafts retain early work. Message-level Little Tutor threads can recover, move, or clear their source anchor without losing the surrounding conversation. Generated files gain consistent open and download controls, while editing or resending a message uses the current model and reply language.

### Checked lessons and portable study materials

Video Lesson narrates through the configured Text-to-Speech provider with Edge fallback, checks browser layout, and runs targeted repairs. Math Animator adds dry-run geometry checks and task-model repairs. Notebook flashcards export to Anki, and Calendar events export as iCalendar files for external calendar apps.

### More models, search providers, and agent options

Claude Code integration gains official SDK model discovery and source-image forwarding. Provider coverage expands with xAI models, Mistral embeddings and voice, You.com and self-hosted Google browser search, plus CloudGPU, LLMTR, and Runcrate gateways. Task models now handle targeted Math Animator and Video Lesson repairs as well as background helpers.

### Retrieval and document fidelity

PageIndex indexing can use the configured Task model, while LlamaIndex folder synchronization publishes one coherent version. MinerU retains reference lists, and hybrid retrieval excludes zero-score BM25 hits. Office and DOCX fallbacks better preserve equations, pictures, slide order, sparse spreadsheet columns, and grouped mathematical terms.

### Reliability across the runtime

This release also hardens archive extraction, Unicode filename handling, cancellation cleanup, voice transcription and audio conversion, tutor-thread recovery, workspace draft saves, and desktop signing and notarization. These fixes reduce partial failures and preserve existing data when an operation cannot complete.

English and Chinese guides are synchronized with this release at [deeptutor.info](https://deeptutor.info/).

## Upgrade Notes

- **Full app:** stop DeepTutor and back up the runtime home, then run `python -m pip install --upgrade "deeptutor[full]==1.7.1"`. Keep the same `DEEPTUTOR_HOME`, run `python -m pip check` and `deeptutor module list`, then restart.
- **Legacy installations:** upgrades from 1.6.15 or earlier must uninstall the legacy `deeptutor-cli` package before installing the new package family. Follow the migration commands in [v1.7.0](ver1-7-0.md); runtime-home data remains separate from installed packages.
- **Source installs:** install `requirements/full.txt`, then `python -m pip install -e . --no-deps`. Core and feature wheels must use matching versions; stop active servers and CLI turns before changing modules.
- **Docker:** pull `ghcr.io/hkuds/deeptutor:1.7.1` or `:latest` and recreate the container with the existing data volume.
- **Desktop previews:** download the matching artifact from a successful Desktop Release workflow run on `dev`; GitHub sign-in is required and artifacts expire after seven days. Windows preview builds are unsigned and may show a SmartScreen warning.
- **Video Lesson:** the backend needs Node.js 22+ and npm. Narration uses the configured speech provider when available, then Edge when installed; without narration, captions remain and lessons play silently.
