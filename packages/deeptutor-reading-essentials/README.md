# deeptutor-reading-essentials

Optional Immersive Reading actions for DeepTutor. The core reader remains a
document renderer with secure extension slots; installing this distribution
adds five independently discoverable entry points: Learn, Test, Read aloud,
Translate and Vocabulary.

```bash
pip install deeptutor-reading-essentials
```

Translation requires an explicitly configured provider. Without one it returns
an actionable configuration card and never affects the core reader.
