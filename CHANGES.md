# GuruAI change log

This branch adds the Sinhala-first GuruAI education extension to DeepTutor.

## Upstream attribution

GuruAI is built on HKUDS/DeepTutor, licensed under Apache 2.0. Existing license, notice, third-party notices, Co-Writer, Research, Book, Notebook, and Admin surfaces remain preserved.

## New in this branch

- Sinhala/English response schema for syllabus-grounded explanations
- Marking-scheme grading contract with method-mark support
- Source/page citation objects designed for textbook and past-paper evidence
- Local-only learner mastery record schema
- MVP architecture notes for PDF syllabus and past-paper ingestion
